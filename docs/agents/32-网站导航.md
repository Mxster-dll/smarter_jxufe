## 32. 网站导航（全校站点目录 + 星标收藏 · 2026-09-19 立）

用户原话：「我希望添加一个网站导航的功能：江西财经大学 教务处 官网 https://jwc.jxufe.edu.cn/ ；江西财经大学 官网 https://www.jxufe.edu.cn/ ；江西财经大学迎新网 https://hello.jxufe.edu.cn/ ；江西财经大学图书馆官网 https://lib.jxufe.edu.cn/ ；江西财经大学综合服务门户平台 http://ehall.jxufe.edu.cn/ ；江西财经大学研究生院官网 https://grs.jxufe.edu.cn/ ；江西财经大学教学管理服务平台 http://xk.jxufe.cn/ ；江西财经大学软件与物联网工程学院 https://software.jxufe.edu.cn/ （各学院你去找然后非学院官网的应该也还要很多其他网站）」

### 32.1 用户拍板的三条口径（改动前先看这里）

- **打开方式 = 一律用系统浏览器**（用户明确否掉「手机内嵌 WebView」）→ 走 `lib/core/web/external_url.dart` 的 `externalUrlOpenerProvider`（`LaunchMode.externalApplication`）。**不得**用 `lib/core/web/in_app_web_screen.dart` 或 `inAppWebViewSupportedProvider`（源码守卫断言页面里既不 import 它们、也不出现 `InAppWebScreen` / `launchUrl(` 字面量）。
- **收录范围 = 全量**（学院 + 职能部门 + 服务系统 + 科研机构 + 其他），现 **137 条**。
- **星标收藏 + 置顶分组**（Hive 持久化）。

### 32.2 分层与唯一清单

- 模型 + 纯函数 = `lib/features/site_nav/domain/campus_site.dart`：`enum CampusSiteCategory{college'学院与学部', department'职能部门', service'服务系统', research'科研机构', other'其他站点'}`（**枚举顺序 = 页面分节顺序**）、`class CampusSite{name,url,category,hot,note}` + `String get host`（`campusSiteHost`）/ `String get key => url`、`campusSiteMatches(site, query)`（名称 / URL / 备注，忽略大小写与首尾空白）、`filterCampusSites(all,{query,category,hotOnly,favoritesOnly,favorites})`（四个条件是**与**）、`campusSiteSections({all,favorites,query,category,hotOnly,favoritesOnly})` → `List<CampusSiteSection{title,key,sites,favorites}>`。
  - **收藏段恒在最前**（`key = 'fav'`），空节不占位；**筛选对收藏段同样生效**（否则按分类筛过之后，收藏段里会冒出被筛掉的站点）。
  - 未开 `favoritesOnly` 时收藏项**在两处都出现**（收藏段 + 自己的分类段）——「置顶快捷区 + 完整目录」就是这个功能的语义；开了 `favoritesOnly` 则**只出收藏段**（否则同一批站点再列一遍）。
- 目录数据 = `lib/features/site_nav/domain/site_directory.dart` 的 `final List<CampusSite> campusSites`（**137 条**：学院与学部 29 / 职能部门 37 / 服务系统 22 / 科研机构 38 / 其他站点 11；`hot: true` 16 条 = 用户点名 8 条 + 统一身份认证 / 网上办事大厅 / 本科招生网 / 邮箱 / 就业网 / 网络教学平台 / 科技与信息化中心 / 教务管理系统）。
- 收藏存储 = `lib/features/site_nav/data/site_favorites.dart`：Hive `Box<String>`、box `siteNavPrefs`、单 key `favorites`（JSON 数组，**存 URL** 而不是名称 → 改名不丢收藏），`class SiteFavoritesStore extends ChangeNotifier with BoxReloadWatcher`（照 `my_campus_prefs.dart`：`ensureLoaded()` 幂等、`bindBoxReload(box, _readFromBox)`、脏数据一律忽略、落盘失败静默降级）+ `siteFavoritesProvider`。**不做账号隔离**（收藏的是学校官网，与学号无关；与「我的校区」同款全局偏好）。
- 页面 = `lib/features/site_nav/presentation/site_nav_screen.dart`：搜索框（无边框圆角 10）+ 筛选胶囊（全部 / 常用 / 我的收藏 / 五个分类，**都带条数**）+ 3px 竖条分节标题（`Key('siteSection-<fav|分类名>')`，测试靠它认段）+ 卡片行（40×40 图标底 + 名称 + `host · note` + 「常用」小标 + 星标 + 复制链接）。**整行 = 系统浏览器打开**，行尾 = 收藏 / 复制（`Clipboard.setData` + SnackBar）。打开失败提示「无法打开 <host>（可能需要校园网）」。

### 32.3 目录数据的采集与核实口径（改目录前必读）

- **权威来源** = 学校官网「机构设置」三页（`https://www.jxufe.edu.cn/news-list-xysz.html` 学院设置 / `news-list-guanlijigou.html` 管理机构 / `news-list-keyanjigou.html` + `news-list-keyanpingtai.html` 科研机构与平台）逐条抓链接；**二次核实** = 对 `*.jxufe.edu.cn` / `*.jxufe.cn` 候选子域做 DNS + HTTP 探活，并以**实际 `<title>`** 命名。

- 首页入口 = `home_service_catalog.dart` 的「网站导航」（`Icons.hub_outlined` + `HomeServiceGroup.info` + `f.siteNav` + `SiteNavScreen()`），排在「规章制度」之后；**目录条目数 29 → 30**，已同步 `test/home_tile_alignment_test.dart`（含一条「在数据与信息组里且页面是 SiteNavScreen」的守卫）。
- 强调色 = `FeaturePalette.siteNav = Color(0xFF6200EA)`（紫族里**唯一的高饱和亮紫**：`#4A148C` 推免 / `#4527A0` 公共查询 / `#6A1B9A` 请假都是低饱和暗紫）+ `FeatureColors.siteNav`。
- 守卫 = `test/site_nav_test.dart`（**31 例** = 24 例纯逻辑 + 7 例 widget）：目录条数与分类分布 / URL 合法且不重复 / 用户点名 8 条原样在表 / 只有 http 的没被改协议 / 空壳与死站没混回来 / 改名后的学院用现名 / 搜索与筛选纯函数（含收藏段恒在最前、`favoritesOnly`、筛选对收藏段生效）/ 收藏落盘往返 + 脏数据 + **外部写入（云同步恢复）反映到内存** / 页面渲染 + 搜索命中 + 打开走 provider（断言 URL）+ 打开失败提示 + 星标与取消 + 复制进剪贴板 + 分类胶囊 + 空收藏提示 / 源码守卫。
  - ⚠ **三条真踩到的坑（写页面测试前必读）**：① **Hive box 必须在 `setUpAll` 的真实异步区里预开**（`await Hive.openBox<String>(siteNavPrefsBoxName)`）—— `Hive.openBox` 对同一 box 名是「单飞」的，第一次打开若落在 `testWidgets` 的假异步区（页面里 `siteFavoritesProvider` 的 `unawaited(ensureLoaded())` 就会），那个 future **永不完成** → widget 测试挂到 `pumpAndSettle` 上限（口径与理由同 `test/theme_dark_test.dart:72-79`）；`deleteFromDisk()` 会把 box 关掉，所以「清库」的 `setUp` 里必须**再预开一次**。② ⚠ **别用 `tester.runAsync` 去建 store**：那样 `_loading` 是真实异步区里完成的 future，假异步区里 `await` 它**永远不恢复**（实测点了星标毫无反应、`store.length` 仍是 0）。③ `tearDownAll` **不要碰 Hive**：widget 测试留在假异步区里的在途 `box.put` 永不完成 → `deleteFromDisk()` / `close()` 一起挂（实测整份测试卡在 `(tearDownAll)` 12 分钟超时），临时目录交给系统回收（同 `test/aa_test.dart:133`）。
  - 另两处小坑：搜索词别用「图书馆」（会同时命中「图书馆 · 图书资源门户」→ `find.byTooltip('收藏')` 撞到 2 个 widget），用域名 `lib.jxufe.edu.cn`；源码守卫**别直接断言 `source.contains('in_app_web')`** —— 页面文档注释里点名了该文件路径就恒为 true，要断言 `import` 行与 `InAppWebScreen` / `inAppWebViewSupportedProvider` 符号。
