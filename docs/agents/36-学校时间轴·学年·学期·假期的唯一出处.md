## 36. 学校时间轴：学年 / 学期 / 假期的唯一出处（2026-09-27 立 · 用户原话：「我们希望可以独立出来被所有模块复用，学年的时间范围就定为该学年第一学期第一天到下学年第一天前一天；假期时间也可以从校历页查，https://jwxt.jxufe.edu.cn/public/SchoolCalendar.jsp」）

**唯一实现 = `lib/features/school_calendar/domain/school_time.dart`**（模块自述：`lib/features/school_calendar/README.md`）。对外取数入口 = `lib/features/school_calendar/data/providers/school_time_providers.dart` 的 `schoolTimeTableProvider`（family by `xn`）/ `schoolYearProvider` / `schoolBreaksProvider`。

### 36.1 口径（三条，都是用户 2026-09-27 裁定）

```dart
class SchoolYear  { int xn; DateTime? firstDay; DateTime? lastDay; }   // 学年
class SchoolBreak { SchoolBreakKind kind; DateTime start; DateTime? end; bool certain; }
class SchoolTimeTable { SchoolTermDates? termAt(int xn, int xq); SchoolYear yearOf(int xn);
                        List<SchoolBreak> breaksOf(int xn); SchoolYear? yearContaining(DateTime); }
// 兜底与换算（§36.3.1）：schoolYearFallback(xn) / schoolYearOrFallback(table, xn) /
// schoolYearStartOf(day) / schoolDayText(day)（yyyy-MM-dd 唯一格式）
```

- **学年 = `[该学年第一学期第一天, 下学年第一学期第一天 − 1 天]`**。2025 学年 = `2025-09-01 ~ 2026-09-06`。
- **下学年未公布 → `lastDay` 留 `null`**（用户原话：取不到就留 null）。`SchoolYear.contains` 对 `lastDay == null` 按**开区间**（不早于起点即算本学年），故「本学年」在学年进行中照样可用。`xn = 2027 / 2028` 的教务页是 **723 字节空壳** → 解析器抛 `SchoolCalendarException('校历 HTML 解析失败：未找到月份表（共 0 张表）')` → provider 跳过该学段。
- **假期以教务校历页为准**：寒 / 暑假结束日**一律派生**为「下一学段学期开始 − 1 天」（教务页 `假期结束日期` 就是这个式子；已公布学年三处逐字吻合：2024 学年 `08-31` ↔ 2025 学年 `09-01`、2025 学年 `09-06` ↔ 2026 学年 `09-07`）。**教务页没有法定节假日**（逐日只有 `workday|nonday`，2026-10-01~07 国庆整段标 workday）——法定节假日仍由小程序校历事件负责（`domain/calendar_day_mark.dart`）。
- **兜底口径**（同日在 §36.3.1 收口）：校历取不到时，调用方可以退回固定窗口 `[xn]-09-01 ~ [xn+1]-08-31`（`schoolYearFallback`）；「日期 → 学年」的算术 = `schoolYearStartOf`。

### 36.2 占位值识别（否则会静默出错）

未公布学段会被教务页「自洽地」编出假日期：**2026 学年的寒假被串成 4 天**（`2027-01-16 ~ 01-19`，因为第二学段被填成 `2027-01-20`），2026 学年第二阶段的 `假期结束日期` 是 `2027-09-30`（真值应约 `2027-09-05`）。故：

- 跨度 < `schoolMinWinterBreakDays`（**14**）/ `schoolMinSummerBreakDays`（**21**）→ 判占位：`end = null, certain = false`（开始日已知就仍算假期起点）。
- **「日期看起来自洽」不能当可信判据** —— 占位值本身就满足「假期结束 + 1 = 下一段开始」。

实测台账（2026-09-27 探针原文，已进 `test/school_time_test.dart` 与模块 README）：

| 学年 | 第一学段 | 寒假（派生） | 第二学段 | 暑期段 | 暑假（派生） | 下学年首日 |
|---|---|---|---|---|---|---|
| 2023 | 09-04~2024-01-19 | 01-20~02-25（37 天） | 02-26~07-03 | 07-04~07-10 | 07-11~09-01（53 天） | 2024-09-02 |
| 2024 | 09-02~2025-01-10 | 01-11~02-16（37 天） | 02-17~06-29 | 06-30~07-04 | 07-05~08-31（58 天） | 2025-09-01 |
| 2025 | 09-01~2026-01-15 | 01-16~03-01（45 天） | 03-02~07-05 | 07-06~07-10 | 07-11~09-06（58 天） | 2026-09-07 |
| 2026 | 09-07~2027-01-15 | 01-16~01-19 ← 占位 | 2027-01-20 ← 占位 | 07-06~07-31 | 08-01~? ← 未公布 | **未公布** |

### 36.3 学期标识归一（三个历史重复实现已收口）

`schoolYearOfTermText` / `schoolTermOfText` / `schoolTermCodeOfText` / `schoolTermFullName` / `schoolTermTextOfCode` —— 接受短码 `251`、完整名 `2025-2026学年第一学期`、只到学年 `2025-2026学年`。**认不出必须返回 `null` / 空串**（绝不兜默认年份，否则会把别学年的课算进本学年）。

- ⚠ **短码必须头尾锚定 `^(\d{2})([1-3])$`**：不锚定的话纯年份 `2025` 会被切成 `20`+`2` → 2020-2021 学年。
- ⚠ 完整学期名**不锚定**（调用方常把「学年学期：」之后整段截下来，可能带尾巴）；`schoolTermFullName` 是**教务原文格式（无空格）**，与界面用的 `schoolTermLabel`（`2025-2026 学年第一学期`，带空格）刻意分开。
- 已迁移：`lib/features/zongce/domain/zc_year_sources.dart` 的 `zcSemesterStartYear`（改为转发别名）、**删除** `lib/features/ims/grades/domain/semester.dart` 整个 `Semester` 类（其唯一用处是 `grades_html_parser.dart` 的学期码提取，改用 `schoolTermCodeOfText`）、`lib/features/ai/tools/score_tools.dart` 的 `aiSemesterLabel`（保留 AI 侧两个兜底：空串给「未知学期」、认不出原样返回，其余交给 `schoolTermTextOfCode`）。

### 36.3.1 学年窗口归一（第二刀 · 同日完成）

**一层两个口径，都由 `domain/school_time.dart` 提供**（2026-09-27 从 zongce / 志愿时长两处收上来）：

| 函数 | 窗口 | 用在哪 |
|---|---|---|
| `schoolYearOrFallback(table, xn)` | 有校历 → `[第一学期第一天, 下学年第一天 − 1 天]`；无 → 固定口径 | **默认选择**：取数入口能拿到 `SchoolTimeTable` 就用它 |
| `schoolYearFallback(xn)` | 固定 `[xn]-09-01 ~ [xn+1]-08-31` | 纯函数 / 离线兜底（综测引擎是纯函数，拿不到时间表） |
| `schoolYearStartOf(day)` | `month >= 9 ? year : year - 1` | 「日期 → 学年起始年」的唯一算术（综测 `zcDefaultYear` 转发它） |

- 已迁移：`lib/features/zongce/domain/zc_models.dart` 的 `zcYearWindowContains` → `schoolYearFallback(yearEnd - 1).contains(d)`；`zcDefaultYear` → `schoolYearStartOf(now)`（**都是转发别名，日期算术已从该文件清零**）。
- 另一处同族（顺带收掉）：`lib/features/competition_award/presentation/award_common.dart` 的「本学年」筛选预设 → `schoolYearFallback(term.xn).firstDay/lastDay`（它仍是**同步纯函数**，拿不到时间表）。⚠ 同一函数里「本学期」预设的兜底区间（`[xn]-09-01 ~ [xn+1]-01-31` / `[xn+1]-02-01 ~ [xn+1]-08-31`）**有意保留** —— 那是「半个学年」的近似，不是学年窗口，且真实学期起止来自校历页而非本层。
- `lib/features/comprehensive_service/domain/volunteer_hours_stats.dart` 的私有 `_inYear` **删除**；`volunteerHoursStats(activities, {required xn, SchoolTimeTable? table})`。
- **两条真实链路都把校历传下去了**：`lib/features/home/data/providers/dashboard_providers.dart` 的 `dashboardVolunteerHoursProvider`（`schoolTimeTableProvider(term.xn)`）、`lib/features/zongce/data/zc_providers.dart` 的 `zcAutoVolunteerProvider`（`schoolTimeTableProvider(yearEnd - 1)`）+ `zcVolunteerHoursForYear(..., table:)` 转发层。
- **行为差异（有意）**：不传表 = 旧口径（`08-31` 收尾），传表 = 真实学年末。实测分歧点 = **09-01 ~ 09-06 这段**：2026-2027 学年 09-07 开学，所以 2026-09-03 记的志愿时长属**上一学年**（`test/volunteer_activity_time_test.dart` 与 `test/zc_year_sources_test.dart` 各有一例把这个分歧钉住）。
- ⚠ `schoolYearStartOf` **不认识校历**（界线恒取 09-01），而真实首日可能是 09-07 → 需要精确归属时用 `SchoolTimeTable.yearContaining`。

### 36.3.2 校历页「学年时间线」卡（2026-09-27 立 · **2026-10-09 改为一根单轴时间线**）

用户 2026-09-27 裁定「融入校历页，包括学期时间与学年时间」→ 先做成「一行一个学段」的
图标 + 文字列表；**2026-10-09 用户否掉那一版（以及与它并列的一版 Mono 风设计稿），
指定「直接用 fluent-design 设计一根单轴时间线」** → 现在是
`lib/features/school_calendar/presentation/widgets/school_year_timeline.dart` 的
`SchoolYearTimeline`（挂在校历页 `_buildSchoolYearCard`）：

- **一根轴 = 一个学年**：4px 圆角轨道（WinUI `ProgressBar` 的形制）横贯卡片，长度按
  真实天数投影；学段 / 假期是**轴上的段**（同一根轴上首尾相接的圆角实心条），
  不再各占一行；
- **段的抽取是纯函数** = `domain/school_time_timeline.dart` 的
  `schoolTimelineSegments(table, xn)` / `schoolTimelineAxis(table, xn)`
  （`SchoolTimelineSegment{name,start,end,kind,note}` / `SchoolTimelineAxis.fractionOf`），
  可脱离 Flutter 单测；
- **待公布 = 段的 `end == null`**：画成**虚线且越往后越淡**（α 1 → .3），
  **不给终点圆点** —— 长度未知就不许用任何视觉手段暗示长度；
- ⚠ **占位链**：教务在未公布学段会「自洽地」编日期（§36.2 的 2026 学年 4 天寒假）。
  判据 = 该学段**起点之前最近的那段假期**是否 `certain == false`；一段不可信 →
  **它后面的整条链都不画**（寒假是编的，「第二学期 01-20 起」自然也是编的）。
  时间线上长度是视觉编码，**宁可少画一段，也不画一段假的 7 个月**；
- **今天** = 轴上唯一的 accent 强标记（圆点 + 「今天 · 第 N 教学周」淡染胶囊，胶囊用
  Fluent 的「accent 8% 底 + accent 字」徽标口径）；今天不在轴上（看历史学年）时不画；
- 标签挂在轴两侧（在校段在上、放假段在下），各两行（段名 `FluentType.bodyStrong` +
  起止 `FluentType.caption`）；**同一侧贪心让位**（相邻至少 12px），让位后中心偏离段
  中心 > 8px 就画 1px 引线接回本段 —— 5 天的「第二阶段」标签比它自己宽几十倍，
  不让位必叠在一起（实测）；
- 月份刻度在轴下方压尾（相邻月名放不下就隔一个画）；整块高度 `SchoolYearTimeline.height` = 136。
- 取不到时间表 → 整卡不画（当前学段仍由「关键日期」覆盖，不出现空壳卡）。
- **与「关键日期」卡的分工**：那张**原样**列当前学段备注（含教务在未公布学段编的占位日期），
  这张只显示**可信的派生结果** —— 实测 2026 学年备注写「假期 2027-01-16 ~ 2027-01-19」
  （4 天占位），本卡只画到「01-16 起 · 待公布」。

⚠ **Fluent 采用点（第 3 处）**：这一块只取 `lib/design/fluent/` 的
**`fluent(context)` 调色板 + `FluentType` 字号档**（4px 栅格 / 4px 圆角 / 无阴影 / 只许
semantic 色，源文件里没有任何字面色值 —— 有源码守卫），**不引入 `FluentCard` 等 Fluent
表面件**，避免校历页里出现两种卡片语汇（§13 的「不反向铺」红线按这条收窄解释）。

预览图（用 `simhei` 代替真实字体渲染，仅看版式）：`docs/design/学年时间线-当前学年.png`
（只公布了头两段）/ `docs/design/学年时间线-完整学年.png`（排满的五段）。
