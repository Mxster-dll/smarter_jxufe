## 38. 填表助手（上传 docx → 自动识别待填项 → 自动填 → 手动改 → 导出）（2026-10-07 立）

用户原话：「我们学校在评优评先方面会让我们填很多材料，但是我们手填的话，要整理很多很乱的」
→ 先答「生成可直接复制的文本」，随即改口：**「算了，我不希望你生成复制文本了，而是允许用户上传一个
docx 文档，然后你自动识别有哪些项需要填，然后把能填的都填了。填不了/不确定的，空着。然后用户可以在你
自动填完后，再手动调整各部分文本。」** 参考表在 `<下载目录>\填材料汇总`（先进个人登记表 / 汇总表、综测
登记表 附件3·5、综测班级汇总表 附件4、企业奖助学金审批表、附加分审核表、候选人简介表 表7·表8）。

### 38.1 分层与唯一实现

| 层 | 文件 | 职责 |
|---|---|---|
| 包 | `lib/features/fill_form/domain/docx_package.dart` | `.docx` = zip：解包 / 重打包，**除 `word/document.xml` 外每个条目逐字节原样回写** |
| DOM | `…/docx_dom.dart` | 按 `w:` **命名空间**找元素、读段落纯文本、把一段文字写回段落 |
| 字段 | `…/docx_fields.dart` | `DocxField`（五种待填项）/ `DocxListTable` / `DocxListColumnKind` |
| 识别 | `…/docx_scan.dart` | `docxScan(XmlDocument) → DocxScan`（纯函数） |
| 写回 | `…/docx_apply.dart` | `docxApplyValues(DocxScan, Map<id,text>) → int`（纯函数） |
| 门面 | `…/docx_form.dart` | `DocxForm.fromBytes` / `export(values)` / `suggestedFileName` |
| 取值 | `…/fill_form_data.dart` | `FillFormData` 快照 + `fillValueFor(field, data)` + 成段文字生成（纯函数） |
| 装配 | `lib/features/fill_form/data/fill_form_providers.dart` | `fillFormDataProvider(学年结束年)` |
| 页面 | `lib/features/fill_form/presentation/fill_form_screen.dart` | 选文件 → 逐项可编辑 → 导出 |

**页面只调纯函数**，不自己解析 XML、不自己拼文案（口径全在 domain，可单测）。

### 38.2 五种待填项（`docx_scan.dart` 的识别口径）

1. **`cell`（整格空）**：标签 = ① 同行**往左**最近的「能当标签的文字」→ ② 往**上**找同网格列的**表头**
   （纵向合并的续格往上取锚格）。两步都要过 `_usableLabel`：纯数字 / `例：国一` / `Ⅰ/Ⅱ/Ⅲ类` / `不填` /
   照片 / 括号说明 / 含「签名·年 月 日·公章」的文字**都不算标签**。
2. **`cellInline`（格内「标签：」段落）**：就地追加（`加、减分项目：` / `德育附加分数合计：` /
   `学生姓名：`）。**段落末尾会补两个全角空格再匹配**，这样「标签独占一段」的写法也能命中。
3. **`cellProse`（提示格 / 标签独占一格）**：格内非空段落**全是提示**（`（德、智、体等方面）` / 签名 /
   `年 月 日`）→ 值写进「第一个提示段之后的第一个空段」，提示与签名行都留着；整格只有一段且以冒号收尾
   （`本人申请理由（…）：`）→ 值作为**新段落**写进同一格，题头保留。
4. **`paragraph`（正文段落）**：`标签：<≥2 个空白>`，空白区间整体替换，**段中空位补一个空格**。
   - **以标签收尾**（`…学号：            专业：`，冒号后没有空白）也会命中，但**只在本段本来就有别的空位时**
     才认 —— 否则《先进个人登记表》标题那种「表1：」也会变成一个待填项（实测多出一条空行）。
5. **`listTable`（清单表）**：整张表当一个 **TSV 多行字段**（用户在一个多行输入框里逐行改）。

**标签归一（`coreLabel`）**：比对与取值前先**摘掉括号说明** —— `培养单位（公章）` → `培养单位`（要的是单位名，
括号只是提醒盖章）；括号里全是说明时（`（学院公章）`）退回原文，交给跳过规则。跳过判据（`_labelIsSkipped`）
用的也是这个「摘掉括号」后的形态。

### 38.3 三条必须记住的实测坑

- **`DocxField.id` 是位置派生的**（`t0.r1.c3` / `b7.12` / `list0`），`export` 每次**从原始字节重新
  解析 + 重扫**再按 id 对位写值 → 反复导出**幂等**（同一份值导两次，不会在已填内容后面再贴一遍）。
- **空值 = 不写**：我们只往「原本就空」的位置写，所以「用户把某一项清空」= 那份文档里还是空的。
- ⚠ **`package:xml` 新建元素一律用 `XmlName.fromString('w:t')`（只给前缀）**，**不要**传 namespaceUri
  —— 传了它会序列化成 `<http://schemas…:w:t>`，Word / python-docx 直接报
  `Failed to parse QName 'http:'`（实测三次导出全部打不开）。只给前缀时它老实写 `w:t`，而根元素上本来
  就声明了 `xmlns:w`。
- ⚠ **Word 的 `<w:t>` 不认 `\n`**：多行文本要拆成多个 `<w:t>` 中间夹 `<w:br/>`（`buildRun` 已处理），
  直接塞换行符会渲染成一个空格。
- ⚠ **`Match` 没有分组偏移**（Dart 只有整体的 `start`/`end`）：段落空位的起点得自己算
  `m.start + group(1).length + 1`（冒号恒为一个 code unit）。

### 38.4 「表单」与「清单表」的分界（踩过）

《先进个人登记表》第一行也是「姓名 │ 空 │ 班级 │ 空 │ 性别 │ 空」—— 判据松一点就会把整张**表单**
当成**人员清单表**，于是全部空位被吞成一行 TSV、别的项一个都识别不出来（实测综测登记表从 34 项退化成
4 项）。`_detectListTable` 的三条闸门：

1. 材料清单 = 表头同时有「项目」+（分值 / 级别 / 获得时间 / 附件数 / 类别）；
2. 人员清单 = 表头有「姓名」或「学号」，**且**（表头行**没有空格** ‖ 识别出的列 ≥5 ‖ 下一行首格是
   「示例」）；
3. 列数 <3 直接不算清单表。

### 38.5 取值口径（`fill_form_data.dart`）

- 学籍 / 成绩 / 综测 / 材料全部**离线**读：`studentInfoRepositoryProvider` 的 `getCachedStudentInfo()`、
  `gePriorGradesProvider`、`zcMaterialsProvider` + `ZcStore.loadManual(学年)`；任何一步失败只让对应那
  一块留空（`fillFormDataProvider` 里逐个 try/catch），**绝不整页报错**。
- 综测分项**全部走引擎**：总分/等次取 `ZcCalcResult`，分项按 `details` 的前缀求和（口径与
  `zongce_widgets.dart` 的 `zcSumDetail` 同源）；**附加分合计不能把几行直接相加**（父级还有封顶
  20/10/2），一律按 `总分 − 基础分 − 民主评议 + 扣分` 反推。
- 「合计」「班级评议 X 等次」各出现 5 次（五育各一行）→ 靠 `DocxField.group`（**该行第一格**，
  纵向合并往上取锚格）消歧；分不清时**留空**。
- 「授予称号」「奖学金等级」「参评项目」「金额」取决于报哪个奖 → **一律留空**给用户填。
- 成段文字（主要表现 / 突出事迹 / 受表彰情况 / 担任学生干部情况 / 科研成果 / 服务社会 / 申请理由 /
  英语水平）由数据成文；结尾那句评价**按数据挑**（没荣誉就不写「表现突出」）。表头写了
  「限 N 字」的字段按 N 字截断（`clipToLimit` 先丢整行再逐字截，学校原话「多出字数按前后顺序直接删除」）。
- 《附加分审核表》按**测评学年**过滤材料（`zcFilterByYear`），行不够时**复制表格行**（`<w:tr>` 深拷贝插在
  最后一条数据行之后、合计行之前）。

### 38.7 守卫 = `test/fill_form_test.dart`（42 例）

用**合成 docx**（内存里现场造 zip）钉住整条链路，不依赖任何外部文件：
① 解包/重打包（其余部件逐字节原样、不是 zip / 不是 OPC → null、旧版 `.doc` → null）；
② 五类待填项的识别 + 「表单不被误判成清单表」+ 两行表头纵向合并继承 + 清单表列语义
+ 「培养单位（公章）：」要填 / 以标签收尾的**标题段**不填；
③ 四种写法 + 清单表复制行 + **导出幂等** + 空值不写；
④ 标签映射（身份/成绩/综测分项/两个 TSV）与「用户自己定的项留空」；
⑤ 成段文字只用真实数据（空数据 → null）+ 限 N 字截断；
⑥ `zcYearGradeStats`（最低单科/学分/挂科，`score<=0` 的非数字成绩不算挂科也不算最低分）；
⑦ 三条 widget / 目录例：**首页目录里「填表助手」自成一组 + 材料库里不再有它**（含源码守卫）、
填表助手页本身能起来、导入后逐项可编辑且「还原」可用、
**整份文档没有待填项时给出原因**（`Key('fillFormNoField')`，而不是一片空白）。

**导入后 0 个待填项**（实测会撞上：选成《评选办法》《名额分配》这类说明文件，或下载到的
是别人**已经填过**的版本）→ 页面给一张写明三种原因 + 「换一份表格」的卡，不再是一个空列表。
