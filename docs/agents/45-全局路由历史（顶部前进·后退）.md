## 45. 全局路由历史（顶部前进 / 后退）（2026-10-09 立）

用户原话：「我希望在顶部增加一个全局路由记录前进/后退，就是记录一下页面跳转，然后我希望
可以点击顶部的按钮，实现页面之间的切换」。

### 45.1 唯一实现 = `lib/core/navigation/route_history.dart`

**模型 = 浏览器式「访问过的位置」**：一条线性列表 + 一个游标，**不是** Flutter 的 Navigator 栈
（那玩意儿只支持 pop，「前进」无从谈起）。

- `RouteHistoryEntry{label, key, restore}` —— 每个位置自带一个 `restore()`：把应用**放回那个位置**。
- `RouteHistory.record(entry)`：追加并**截断前进尾巴**（浏览器语义）；`key` 与当前一条相同 → 直接
  忽略（面板来回点不刷屏）。
- `RouteHistory.goBack() / goForward() / goTo(i)`：**只移动游标 + 调目标那条的 `restore()`**，
  完全不碰 Navigator 栈。⚠ `restore` 的语义是「**目标那一格**的动作」（把我放回这个状态），
  不是「离开当前这一格」——写守卫测试时最容易把这两者搞混（第一版就写错过）。
- **`restore == null` 的位置回不去**：`canGoBack` / `canGoForward` 判的是**目标那一格**能不能重建
  → 按钮禁用。判据只挡「进入它」，不挡「离开它」（当前停在不可重建的一格上时，后退照样可用）。
- `routeHistoryProvider`（`ChangeNotifierProvider`，**非 autoDispose**：历史必须跨页面活着）。

### 45.2 记录点（v1 只有两处，别再到处塞）

1. **跳转缝** `lib/core/navigation/service_nav.dart`：`registerServiceScreen(id, builder, label: …)`
   多了一个 `label`（= 顶部下拉里的显示名），三个动作（`openServiceScreen` /
   `resetToServiceScreen` / `replaceServiceScreen`）跳完各喊一次历史钩子。
   ⚠ **缝不许 import provider**：它只喊组装根注入的 `serviceNavHistoryRecorder(id, label, canRestore)`
   （参数刻意只用基本类型，core 里互不 import）；`restore` 走**无 context** 的
   `openServiceScreenById(id)`，因此组装根要用 `attachServiceNavigator(navigatorKey.currentState)`
   把 Navigator 交给缝（历史回放时手里没有 `BuildContext`）。
2. **侧栏视图的面板切换** `home_screen.dart` 的 `_select` / `_selectFooter`：切换前记「离开的位置」、
   切换后记「到达的位置」→ 于是从任何一格都能按后退回到上一格。`restore` 直接改选中项、
   **不走 `_select`**（回放时游标已经停在那一条上，再记一笔会把历史顶歪）。

### 45.3 界面 = 顶部那条栏里的品牌组

`lib/design/window_title_bar.dart` 的 `WindowTitleBarHistory`（挂在 brand 那一组里，跟着 logo 走，
换「logo / 三键左右互换」时整组一起动）：

- 左键后退 / 右键前进：不可用时 `onPressed: null`（**禁用而不是藏起来** —— 藏起来按钮会左右横跳）；
- 第三枚 = 历史下拉（`PopupMenuButton`），按走过的顺序列出，当前那条打勾，点一行 `goTo`；
- key：`windowTitleBarBack` / `windowTitleBarForward` / `windowTitleBarHistoryMenu`。

### 45.4 边界（v1 有意留下的）

- **只有上面那两处会记**：feature 里自己 `Navigator.push` 出去的二级页（阅读器 / 答题页 / 课程详情）
  **不进历史** —— 它们照样能正常前进后退（那些按钮管的是「访问过的位置」，不是浏览器栈）。
- **没有键盘快捷键**：`Alt+←/→` 还没接（§43 的栏内动作要 context + `mounted` 守卫，接的时候注意）。
- **移动端看不到**：这条栏本身是 Windows 专属（`windowTitleBarSupported`），Android 上没有它 →
  历史按钮也就没有；真要在手机上给，得另做一处入口（页面 AppBar）。
- 守卫 = `test/route_history_test.dart`（账本语义 8 例：去重 / 截断 / goTo / 不可重建 / clear；
  标题栏按钮 3 例：空历史禁用、可点、下拉跳转；缝的 label 与「没 Navigator 不记假历史」2 例）
  + `test/service_nav_test.dart`、`test/core_conventions_test.dart` 的既有守卫（缝不许 import feature、
  组装根注册 id）。
