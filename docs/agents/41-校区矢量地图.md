# §41 校区矢量地图（2026-10-08 立）

> 用户原话：「我们现在希望生成江西财经大学四个校区的地图，就放到当前的地图功能内。然后可以手动切换两种风格的地图。」
> 二轮拍板：**两种风格 = 浅色 / 深色主题联动** + **矢量图与官网原图对照**；**渲染 = Flutter CustomPainter 原生绘制**；**范围 = 地图页内切换校区 + 「我的校区」默认选中**。

## 41.1 一句话口径

四校区矢量底图 = **`assets/campus_map/<校区枚举名>.json`**（随包 asset，不发网络），
由 `tool/jxufe_map/` 的脚本从 **OpenStreetMap** 快照裁出来；
渲染 = `campus_map_painter.dart` 的 `CampusMapPainter`（**不依赖任何地图 SDK**），
挂在「校区地图」页的「矢量图」那一态上（另一态是原有官网原图）。

## 41.3 渲染口径（改之前先看这里）

### 坐标系

- asset 里**存 WGS84 经纬度**（`[lon, lat]`，与 GeoJSON 一致），另带 `origin`（校区中心）。
- 加载时用 `CampusProjection` 投到**局部米制平面**：经度 × `111320·cos(originLat)`、纬度 × `110574`。
  校区尺度（<2km）下误差远小于 1 米，换来渲染端每次只要两次乘加。
- 领域模型的 **y 轴向北为正**；翻转换算只发生在 `CampusMapPainter` 里
  （`canvas.scale(1, -1)` + `screenY = dy - y·scale`）。

### 绘制顺序（改顺序 = 换了一张图）

```
地面底色 → 绿地 → 运动场 → 水面（描边）→ 河道 → 道路（先路缘后路面，画两遍）→ 建筑（填 + 描边）→ 标注 → 高亮
```

- 道路用**两遍描边**做路缘（参考实现里的同一手法，比给每条路配两个颜色省事）。
- 线宽按**米**给（`2.0 + width·2.6`，`width` 是生成脚本给的分级档 1..5），
  只有**建筑描边**按屏幕像素恒定（世界坐标里除一个 `scale`）。
- **视口裁剪**：每层先用包围盒与可见世界矩形粗筛，放很大时不会白画上千个点。

### 标注排版 = 按优先级贪心占位

1. 只画 `priority >= CampusMapGeometry.labelMinPriority`（= 2）的标签 ——
   `priority == 1` 的是「周边小店」这类噪声，默认不上屏。
2. 按 `priority` 降序（3 = 图书馆/食堂/校门这类找路锚点），逐个测量文字框。
3. 与**已上屏的任何一个**框相交就放弃（锚点级之间也让位 ——
   「图书馆」和「一食堂」叠在一起同样读不出来）。
4. 出屏幕的不画。

**与参考实现的区别（有意）**：杭州那套用的是「物理松弛 + 位移超限即隐藏」，
因为它的标签会随手指拖动实时重排；校区图的标签是静态的，**贪心一次算完更简单、
且结果稳定**（同样的缩放永远得到同样的图），也不用每帧做 60 轮 O(n²) 迭代。

文字大小跟缩放走（`10.5·√(zoom)`，夹在 9–20px），即**放大地图时文字变大但慢于地图**。

## 41.4 两种风格口径

`CampusMapStyleKind{light, dark}`，`resolveCampusMapStyle(manual:, platformBrightness:)`：

| 情形 | 结果 |
|---|---|
| 用户没手选过（`campusMapPrefs` 里没有 `style` 键） | **跟随 App 主题** |
| 用户手选过 | 以手选为准，**哪怕与主题相反** |

- 色值**全部**登记在 `lib/design/status_palette.dart` 的 `CampusMapTone`
  （页面里不许写 `Color(0x…)`，守卫见 `test/core_conventions_test.dart`）。
- 两套的 `accent` 都是校红系（`#C3282E` / 深色款用亮一档的 `#E57373`），
  换风格时品牌色不丢。
- 页内切换按钮在卡片右下角（图标 = **将要切到**的那一款），点了弹 SnackBar 告知；
  偏好**不参与云同步**（`libsp_payload.dart` 没登记它 —— 「这台设备看地图想用哪种配色」
  跟着账号跨设备同步没有意义）。

## 41.5 数据来源与实测台账（**改数据前必读**）

数据 = OpenStreetMap（**ODbL**，署名已写进 asset 的 `attribution`，界面脚注也显示）。

⚠ **原始 Overpass 快照与预览图刻意放在仓库之外**：
`%LOCALAPPDATA%\smarter_jxufe\jxufe_map\`（可用 `JXUFE_MAP_RAW` 覆盖）。
**不是** `.gitignore` 的问题 —— OSM 原始 JSON 带着商家的**真实手机号**
（`contact:phone`），而 `test/privacy_guard_test.dart` 会扫 `tool/` 且
**不看 `.gitignore`**，留在仓库里必然报「手机号 N 命中」（实测数十条）。
加 ignore 没用，必须真的搬出去。只有脱敏后的 `assets/campus_map/*.json` 入库。

### ⚠ 三个坑（首版全踩过）

1. **不能按 `name` 匹配校区多边形**：蛟桥园是**2 个 way**（南北区），只匹配一个会只画一半校园。
2. **枫林园在 OSM 里被写成「枫庐园」**（庐/林 之误）→ 按官方名匹配一个多边形都拿不到。
3. **麦庐园的 bbox 里混着东华理工大学**：广兰校区（`28.720,115.802`）与枫林校区
   （`28.736,115.827`），建筑名是「核工楼 / 测绘楼 / 软件楼 / 地学楼 /
   国防科技楼（核资源国重实验室）」。**首版按 bbox 裁剪，把 95 栋外校建筑画进了枫林园地图。**
   → 现在一律**按校区多边形裁剪**，并有守卫测试 `★ 别校的建筑不许出现在财大地图里`。

唯一出处 = `tool/jxufe_map/campus_anchors.py`（按**校区中心坐标**挑多边形，不按名字）。
详细核查过程与四校区坐标见 `tool/jxufe_map/NOTES.md`。

### 数据丰富度（2026-10 实测）

| 校区 | 建筑 | 道路 | 标签 | 可用性 |
|---|---|---|---|---|
| 蛟桥园 | 46 | 53 | 30 | ✅ 好 |
| 麦庐园 | 42 | 47 | 55 | ✅ 好 |
| 枫林园 | **2** | 17 | 5 | ⚠ OSM 上几乎是空白 |
| 青山园 | **2** | 5 | 1 | ⚠ OSM 上几乎是空白 |

**枫林园 / 青山园 在 OSM 上没有测绘**（不是脚本的问题：原始 bbox 里
青山园有 354 栋建筑，但**多边形内只有 2 栋无名的**，其余全是校外的
「龙泉湾N号楼」「中海·寰宇天下N栋」「省环保厅」）。处理口径 = **不编造数据**：

- `CampusMapGeometry.isSparse`（建筑 < 8 栋）→ 界面用 `FluentInfoBar` **如实说明**
  「OSM 在这个校区只测了很少的楼，所以矢量图比较空 —— **不是加载失败**」，并指向官网原图。
- 想画好看只有两条路：**去 OSM 补测**（贡献上游），或**按官方栅格图人工描点**
  （`assets/images/campus_maps/fly.jpg` / `qsxq.jpg` 可当描图底稿）。

## 41.6 重新生成（改了数据就重跑这三步）

```powershell
$py = '<仓库根>\.venv\Scripts\python.exe'
& $py tool\jxufe_map\fetch_osm.py          # 抓 OSM（幂等，--force 重抓，--only KEY 单校区）
& $py tool\jxufe_map\build_geometry.py     # 裁成 assets/campus_map/*.json
& '<PYTHON>\python.exe' tool\jxufe_map\render_preview.py
# → %LOCALAPPDATA%\smarter_jxufe\jxufe_map\*.png，肉眼核对
```

- `render_preview.py` 需要 **Pillow**（仓库 `.venv` 里没装，用系统 Python 跑）。
- Overpass 实测频繁 504/500（限流），`fetch_osm.py` 已把每个校区拆成
  **面积 / 线 / 命名节点三条小查询**并带 15s×(n) 退避 —— 别改回一条大 UNION 查询。
- 另有 `verify_campus_location.py` / `locate_campuses.py` 是**一次性定位脚本**
  （用官方地址里的路名 + 候选建筑簇判定校区归属），留着是为了将来复核。

## 41.7 守卫

**两个文件、42 例**（3 秒跑完）：

### `test/campus_map_test.dart`（34 例）

| 组 | 守什么 |
|---|---|
| 真实 asset 台账 | 四份 asset 都在；`id` / 官方名与 `MyCampus` 对齐（**漂了就红**）；ODbL 署名不许删；裁剪依据必须是 `osm-campus-polygon`（不许退回 bbox 兜底）；蛟桥园/麦庐园建筑数不许掉到 20 以下；**★ 别校建筑不许出现**；标签优先级只在 1..3 且非稀疏校区必须有锚点 |

| 风格解析 | 手动优先 / 否则跟主题的真值表；两套关键色值互不相同、**深色底图够暗、浅色够亮**（防写反）；`fromName` 容错 |

### `test/campus_map_store_test.dart`（8 例）

风格偏好的 store 契约：默认跟随主题 · **save 后立刻生效（内存先改）** ·
**新实例能读回落盘值** · toggle 来回切 · `save(null)` 删键 · 垃圾值视作未设置 ·
重复 save 不重复通知 · 枚举 `other`/`fromName`。

（实测踩过）。所以「要真实 IO 的测试」必须和「要 pump 的测试」分文件放。

另有 `test/my_campus_test.dart` 的老守卫继续管着 `campusMapEntries` 与
`MyCampus.mapEntryNames` 的映射（本次**没动**这两个）。

## 41.8 ⚠ 写这页测试踩过的五个坑（照抄时先看这里）

1. **默认视口 800×600 太矮**：地图卡片（宽屏 16:9 / 窄屏 4:3，夹在 260–520）
   加上页头之后，卡片右下角那三个工具按钮会落在 **y≈658** ——
   **超出视口 → `tester.tap` 静默打不中**（不报错，只是状态不变）。
   实测 `tester.getRect` 给的是 `fromLTRB(698, 638, 738, 678)`。
   → 冒烟测试一律 `tester.view.physicalSize = Size(1000, 1000)` 起步。
2. **`ListView` 不构建视口外的子项**：官网原图那 7 张卡片里，**第 6 张之后
   `find.text` 永远找不到**（不是文字错了，是压根没 build）。
   → 只断言首批可见的那条，别断言「蛟桥园北区」。
3. **脚注必须放进卡片里**：一开始把 `_footnote` 当 `ListView` 的第二个 child，
   卡片本身就 400+ 高 → 脚注落在视口外 → **用户根本看不到**（测试也找不到）。
   挪进 `_MapCard` 的 `Column` 里才对。
4. **`assert` 别拿 override 的名字**：`CampusVectorEntry.name` 取的是
   `MyCampus.label`（「蛟桥园校区」），**不是** asset 里的 `name`；
   测试里 override 成 `'$id 校区'` 之后断言 `find.text('qingshan 校区')` 永远是 0。
5. **Hive 偏好是懒打开的，真实 IO 与 `testWidgets` 的假时钟互斥**：
   - `Hive.init` 用**本文件专属**的临时目录（`createTempSync('campus_map_test_')`）——
     直接用 `Directory.systemTemp.path` 会与别的测试文件 / 残留进程抢
     `*.lock`，报 `PathAccessException: lock failed … (errno = 33)`，整组瞬间全红。
   - `openBox` / `clear` 只在 `setUpAll` / `tearDownAll` 或 `tester.runAsync` 里做；
     放进 `setUp` 或测试体会**挂住整份文件**。
   - 因此 `CampusMapStore.save()` 刻意**内存先改 + 通知同步发、落盘后台补** ——
     「点一下立刻变」不依赖磁盘快慢，测试也就不用等 IO。
