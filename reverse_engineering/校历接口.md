# 教务校历接口（免登录 · jwxt.jxufe.edu.cn）

> 逆向时间：2026-09。结论：**完全免令牌**，仅需匿名 JSESSIONID 会话。
> 对应 App 实现：`lib/features/school_calendar/`（主页宫格「校历」入口）。

## 访问链路

1. `GET https://jwxt.jxufe.edu.cn/public/SchoolCalendar.jsp`
   （匿名，响应 Set-Cookie: `JSESSIONID=...`；页面 GBK 编码）
2. 复用该 Cookie，`POST https://jwxt.jxufe.edu.cn/public/SchoolCalendar.show.jsp?random=<任意小数>`
   form-urlencoded 提交：

   | 参数 | 值 | 说明 |
   |---|---|---|
   | `menucode` | （空） | |
   | `xn` | 2025 | 学年起始年（2025 = 2025-2026 学年） |
   | `xq_m` | 0/1/2 | 0=第一学期(秋 9~1月) · 1=第二学期(春 2/3~7月) · 2=第二阶段(暑 7~9月) |
   | `rad` | 1 | 方式一：结构化表格；方式二(2)引用静态图 schoolCalendar.png，与学期无关不可用 |
   | `sel_xn_xq` | `2025-0` | 冗余字段，随 xn/xq_m 携带 |

   **必须同会话**：不带 Cookie（每次新 session）时 show.jsp 恒返回 ~723B 空模板
   （此前误判接口废弃，实为会话问题）。

## 响应结构（rad=1，GBK HTML）

- 外层布局表：左列自上而下多个「月份表」，右列 `<textarea name="bz">` 备注。
- 每个月份表：
  - 第 1 行：`月份` + 跨 7 列本月值（如 `2026-03`）；
  - 第 2 行：`周次` + `一~日` 表头；
  - 数据行：第 1 格 = 教学周次（跨月连续编号；当月首周与上月重叠时标同号），
    第 2~8 格 = 周一~周日日期，周末日期包 `<span class='nonday'>`，
    空位为 `&nbsp;`；末尾可有整行空白缓冲行。
- 备注 textarea 纯文本行，如：
  - 2025-2026 第一学期：学期开始 2025-09-01 / 结束 2026-01-15；假期 2026-01-16 ~ 2026-03-01
  - 2025-2026 第二学期：学期 2026-03-02 ~ 2026-07-05（无假期行）
  - 2025-2026 第二阶段：学期 2026-07-06 ~ 07-10；假期 2026-07-11 ~ 2026-09-06

## 学段模型（xn_xq 口径，与 App 课表 currentTermOf 一致）

| xq_m | 名称 | 覆盖月份 | 备注日期样例(2025-2026) |
|---|---|---|---|
| 0 | 第一学期 | 9 ~ 次年1(+3 预览行) | 2025-09-01 ~ 2026-01-15 |
| 1 | 第二学期 | 2/3 ~ 7 | 2026-03-02 ~ 2026-07-05 |
| 2 | 第二阶段 | 7 ~ 9 | 短学期 07-06~07-10 |

实测标题随 (xn, xq_m)：`江西财经大学2025-2026学年第一学期校历` 等。

## App 侧实现要点

- `SchoolCalendarRemoteDataSource`：GET 首页 → 正则提取 `JSESSIONID=` 缓存 →
  POST 带 `Cookie: JSESSIONID=...`；响应按 charset 用 `fast_gbk` 解码（GBK）。
- `SchoolCalendarHtmlParser`：用 `package:html` 解析；月份表判定 =
  首行恰好 2 个 td（`月份` + `\d{4}-\d{1,2}`），避免误吞外层布局表。
- 校验：`test/school_calendar_parser_test.dart`（fixture 在 `test/fixtures/_cal_xq{0,1,2}.html`，
  为 2025-2026 三学段真实抓包存档）。
- 页内「凭证已失效」提示脚本 = 会话过期，清除缓存 Cookie 后重试。

## 历史踩坑

- 每次请求新 session → show.jsp 恒空（723B），误判「接口废弃」。
- rad2 的 `schoolCalendar.png` 是单张静态图（29KB，不随学期变），不能用于学期切换。
- 方式三 rad3 → `SchoolCalendar.showgs3.jsp` 需登录凭证，不可用。

## 小程序「智慧江财-校历」数据源（官方逐日安排）

App 校历页另有「官方安排」区 = 智慧江财小程序校历的学期逐日安排
（放假/补课/运动会/期中/军训/报到等），由下述接口而来。

### 应用与页面定位

- 校历应用：appid `1576047674410`，applicationId 203，WeX5 v3 H5 应用
  `wxcourse.jxufe.cn/1576047674410/v-*/jxufe/schoolCalendar/index.w`。
- 页面再调两数据接口（`interface/api/interface/*`，JSON body，强鉴权）。

### 数据接口

| 接口 | 用途 |
|---|---|
| POST `/interface/api/interface/getSchoolCalendar` | 学期记录列表：`{id,term,start_date,end_date,remark,…}`；pageSize 20 一次取全（现 19 条） |
| POST `/interface/api/interface/getSchoolCalendarArrange` | 教学周调整：`{cdate,week(位掩码),change_type,class_day,class_week}`；change_type 1=放假 0=补课 2=运动会 |

- `term` = 学年起始年后两位 + 段码（1=秋 9~1 月，2=春 2~7 月）；**无暑期段**。
  与 IMS (xn,xq)：`term == (xn-2000) + (xq==0?'1':'2')`。
- `remark`（HTML）两版式：近两年 table 式（`<strong>` 教职员工/本科生/研究生 分节 +
  日期/事件行）或 `<p>` 短行式 → 解析为 `WxCalEvent{from,to,text,category}`；
  2017~2025 秋为整段通知文体 → 保留原文 notes（UI 折叠展示）。

### 鉴权与签名（bn 三参数）

- 服务端校验：无 GUID → `10004 参数缺失`；假签名 → `10005 参数非法篡改`；
  假 GUID + 真签名 → `code 0 无访问权限`（服务端查库）。**必须真实平台 GUID**。
- 签名算法（逆向自 `wxcourse.jxufe.cn/dir/usr/local/wisdomPlatform/file/jssdk/V1.8/h5_jssdk_V1.8.js`，
  存档 `tools/_h5jssdk_v18.js`）：
  - appSecret 硬编码 `bainian!@#`；
  - 参数（含注入 `bn_accessKey=GUID`、`bn_timestamp=毫秒`、`bn_nonce=base24 随机`）
    按键名排序拼 `k=v&…&bn_secretKey=bainian!@#` → MD5 → 大写 32 hex = `bn_sign`；
  - 请求体剔除 `bn_accessKey`。
  - Dart 复刻见 `lib/features/school_calendar/data/datasources/wxcal_remote_datasource.dart`
    的 `bnSignedBody`；python 验证与抓包真值一致。

### App 端实现（合并呈现）

- 实时优先：设置中填入平台 GUID（等同微信账号标识，仅微信授权可得）→
  Dio（base wxcourse.jxufe.cn + servicewechat Referer）直连，进页自动拉最新学期。
- 兜底：无 GUID / 实时失败 → 内置离线快照
  `lib/features/school_calendar/data/wxcal_offline_data.dart`
  （生成自 `reverse_engineering/wxcal_calendars_full.json`，抓取于 2026-09，19 学期）。
- UI：校历页「官方安排」卡在「关键日期」卡下、月历前；事件按日期升序，
  icon 按关键词（放假/考试/军训/运动会/报到/上课）；paragraph 学期弹窗看全文。
  暑期段（xq=2）无对应数据显示提示行。
- 测试 `test/wxcal_remark_parser_test.dart`（fixtures `wxcal_rem_{261,252,251}.html`）。

### 新学年数据更新（tools 脚本链）

1. 用户微信打开智慧江财 → 校历页（一次性抓包得 GUID，等同平台账号标识）。
2. 终端：`python tools/_wxcal_fetch.py <GUID>`（复刻签名拉 getSchoolCalendar 全量）
   → 覆写 `reverse_engineering/wxcal_calendars_full.json`。
3. `python tools/_wxcal_parse_events.py` → `wxcal_events_parsed.json`。
4. `python tools/_wxcal_gen_offline.py` → 重生成 `wxcal_offline_data.dart`。
5. `flutter analyze` + 更新 parser fixture（若新版式）。
