## 1. 它是什么

`checkAppAuth` 的 `memo` 原文：

> 本应用为全体师生提供网络服务，包括**上网记录、历史账单、充值明细、业务办理记录**查看等。

本体是**广州热点软件（Dr.COM）「用户自助服务系统」**（页面页脚：`版权所有© 广州热点软件科技股份有限公司 1995-2017`），
挂在学校门户反代路径下：`https://wxcourse.jxufe.cn/1575336885141/`。

站内结构（全部实测）：

| 页 | 路径 | 内容 |
|---|---|---|
| 首页 | `/dashboard` | 账号状态、已用时长/流量、余额、套餐、计费周期、**在线信息**、**近期上网记录** |
| 账单 | `/bill` → 4 个子页 | 上网记录 / 历史账单 / 充值明细 / 业务办理记录 |
| 服务 | `/service` | 账号报停 / 账号复通（+复通记录）/ 预约套餐 / 我的设备 / 资费介绍 / 绑定运营商账号 |
| 账户充值 | `/service/userRecharge` | 在线充值 / 在线充值记录 / **微信充值**（跳 `self.jxufe.cn/WebPay`） |
| 设置 | `/setting` | 用户详细资料（可改）/ 修改密码 |

## 2. 自动登录链（关键：`userId` 一个参数）

```
1) GET https://wxcourse.jxufe.cn/platForm/api/littleProgram/application/checkAppAuth
        ?appid=1575336885141&platformUsername=<GUID>
   → result.username = <enc 学号>          # 形如 AAAAAAAAAAAAAAAAAAAAAA==
     result.pageUrl  = https://wxcourse.jxufe.cn/1575336885141//login/verifyByWeChat
                       ?cardinfo=<44 字符加密串>&sno=0000000&openId=<44 字符加密串>
                       &deptName=<学院>&deptCode=143&cname=<姓名>&sex=男

2) GET <pageUrl>&userId=<urlencode(enc)>
   → 302  Location: https://wxcourse.jxufe.cn/1575336885141/dashboard;jsessionid=…
          Set-Cookie: JSESSIONID=<32 位大写十六进制>; Path=/; HttpOnly

3) 之后所有业务请求带 Cookie: JSESSIONID=<上一步的值> 即可（也支持 ;jsessionid= 路径重写，
   但只靠 Cookie 就够 → Dart 侧无需处理 URL 重写）。
```

**为什么之前一直失败**：只带 `pageUrl` 自带的参数一律 302 回 `/login/`。小程序
`app.js enterApp` 对 `type==3` 的应用会拼
`appName=&username=&url=&jssdk_url=&appid=&casLogin=` 交给 `pages/modules/app/detail/view`，
该页 `onLoad` 再还原（`|`→`&`、`@`→`=`、`#`→`?`）并**追加
`userId/jwtToken/accessKey/colleageCode/jssdk_url/appid/v`**。逐项实测：**只有 `userId` 是登录必需的**
（`jwtToken` 传空串也行，`accessKey/colleageCode` 可省）。

**会话失效判定**：会话过期时业务请求会 302/200 返回登录页（页面标题「用户自助服务系统」+
`name="password"`）→ App 侧识别该特征后**自动重登一次并重试**。

**CSRF**：写操作要求每页现取 token，且两种写法都有：
`var AJAXCSRFTOKEN = '…'`（报停/复通，以及 `"ajaxCsrfToken=" + '…'` 的解绑设备）；
隐藏域 `<input type="hidden" name="csrftoken" value="…">`（预约套餐、改密码、改资料）。
⇒ **一律先 GET 对应页面取 token 再 POST**。

## 3. 读接口

| 接口 | 必带参数 | 返回 | 说明 |
|---|---|---|---|
| `GET /dashboard` | — | HTML（内嵌 `window.user = (…)({…})`） | 账号概览的唯一来源。⚠ `dashboard/refreshaccount` 是 fire-and-forget（**空响应**），拿不到账号 |
| `GET /dashboard/getOnlineList` | — | `[{sessionId, ip, mac, loginTime("yyyy-MM-dd HH:mm:ss"), useTime(秒), upFlow/downFlow(字节,字符串), terminalType("#PC"/"#移动终端"), brasid, userId}]` | 在线会话，可强制下线 |
| `GET /dashboard/getLoginHistory` | — | 数组行 `[上线ms, 注销ms, ip, mac, 时长分, 流量MB, 计费方式(1时长/2流量/3包月), 计费金额, 主机名, 终端类型, …]` | 首页「近期上网记录」，最多 5 条；注销时间为 `null` = 在线中 |
| `GET /bill/getUserOnlineLog` | **`startTime`/`endTime`（`yyyy-MM-dd`）必带**，否则空 | `{rows:[{loginTime, logoutTime, time(分), flow(MB), costMoney, internetUpFlow/internetDownFlow, chinanetUpFlow/chinanetDownFlow, userIp, macAddress, nasIp, nasPort, userRealName, …}], summary:{COU}, total}` | 上网记录明细 |
| `GET /bill/getMonthPay` | **`year` 必带**，否则返回 `{}` | `{summary:{USETIME, USEBASEMONEY, USEFLOW, USEDMONEY}, total, rows:[[开始ms, 结束ms, 套餐, 基本月租, 时长/流量计费, 时长分, 流量MB, 出账ms]]}` | 历史账单。⚠ `rows` 的结束时间是**开区间端点**（= 下一期开始），学校页面显示的结束日 = 该时刻**减一天**（App 侧 `NetworkMonthBill.endDay`） |
| `GET /bill/getPayMent` | — | `{rows:[[交费时间, 交费类型, 金额, 受理终端, 备注]]}` | 充值明细（本账号为空） |
| `GET /bill/getOperatorLog` | — | `{rows:[[办理时间, 业务描述, 受理终端, ?, 备注]]}` | 业务办理记录 |
| `GET /service/getMacList` | `pageSize`/`pageNumber` | `{rows:[[在线状态(0离线/1在线), MAC, 终端信息, 最近登录时间, 最近登录IP]], total}` | 我的设备 |
| `GET /service/getUserGroups` | — | `{rows:[{id, defaultName, extend, code, userGroupId}], total}` | 资费介绍（`id` 也可作预约套餐的 `serid`） |
| `GET /service/getStopLog` | `pageSize`/`pageNumber` | `{rows:[{fldoperatedate, fldoperateid, fldadminid, fldmemo}], total}` | 报停记录 |
| `GET /service/goReopenLog` | 同上 | `{rows:[{fldoperatedate, fldnewvalue, fldoldvalue, fldmemo, …}], total}` | 复通记录（`fldoldvalue` 形如 `0/余额不足，系统停机`） |
| `GET /service/packageLog` | 同上 | `{rows:[{fldchangedate, fldexcutedate, flddefaultname1(原套餐), flddefaultname2(预约套餐), fldstate, fldextend}], total}` | 套餐变更日志 |
| `GET /service/onlinePayLog` | — | `{rows:[…]}` | 在线充值记录 |
| `/bill/exportUserOnlineLog?type=1\|2` | `type=2` 带 `startTime` | 文件下载 | 上网记录导出（App 未做） |

### ⚠ `Content-Type` 不可靠（真机踩到的坑）

实测各接口的响应头：

| 接口 | Content-Type |
|---|---|
| `dashboard/getOnlineList` | `application/json;charset=UTF-8` |
| `service/getMacList` / `service/getUserGroups` | `application/json;charset=UTF8` |
| **`dashboard/getLoginHistory`** | **无** |
| **`bill/getMonthPay`** | **无** |
| **`bill/getPayMent`** / **`bill/getOperatorLog`** | **无** |

正文全是 JSON。若让 HTTP 客户端按内容协商自动解码，这些接口会退回 `String` →
解析层静默得到空集合 → 界面显示「暂无记录」。**App 侧一律 `ResponseType.plain` + 自行 `jsonDecode`**
（`NetworkServiceRemoteDataSource._decodeJson`）。

### 账号概览字段（`window.user`，实测值）

`userName`(学号) / `userRealName` / `leftMoney`(余额 12.5) / `useFlow`(本周期流量 MB) /
`useTime`(本周期时长 分钟) / `leftFlow` / `leftTime` / `macAddress`(分号分隔多个 MAC) /
`ipCount` / `multiLogin` / `useFlag`(1 正常 / 0 停机) / `startDate` / `stopDate`(失效日期) /
`serviceDefault.defaultName`(套餐名) / `serviceDefault.extend`(适用区域) /
`userGroup.payStyle`(**套餐计费方式**，3=包月；⚠ 顶层 `payStyle` 恒为 0，别用) /
`userGroup.userGroupDescription` / `userGroup.ipMaxCount`(最大在线数) /
`userPassword`(明文上网密码) / `userIdNumber`(身份证) / `userId`(Dr.COM 内部 id)。

## 4. 写接口

| 操作 | 请求 | 参数 | token 来源 |
|---|---|---|---|
| 立即报停 | `POST /service/stop` | `ajaxCsrfToken`, `flag=1` | `/service/goStop` 页 `AJAXCSRFTOKEN` |
| 预约报停 | `POST /service/stop` | `ajaxCsrfToken`, `flag=2` | 同上 |
| 取消预约报停 | `POST /service/undoStop` | `ajaxCsrfToken` | 同上 |
| 立即复通 | `POST /service/reOpen` | `flag=1`, `ajaxCsrfToken` | `/service/goReopen` 页 `AJAXCSRFTOKEN` |
| 预约复通 | `POST /service/reOpen` | `flag=2`, `date=yyyy-MM-dd`（**必须 ≥ 明天**）, `ajaxCsrfToken` | 同上 |
| 取消预约复通 | `POST /service/undoReOpen` | `ajaxCsrfToken` | 同上 |
| 预约套餐 | `POST /service/doPackage` | `csrftoken`, `serid`（页面卡片 `data-package`） | `/service/package` 页隐藏域 `csrftoken` |
| 取消预约套餐 | `POST /service/undoPackage` | `ajaxCsrfToken` | `/service/package` 页 `AJAXCSRFTOKEN` |
| 解绑设备 | `GET /service/unbindmac?mac=<MAC>&ajaxCsrfToken=<tok>` | — | `/service/myMac` 页内联 `"ajaxCsrfToken=" + '…'` |
| 强制下线 | `GET /dashboard/tooffline?sessionid=<sessionId>` | — | 无需 token |
| 修改上网密码 | `POST /setting/changePasswordMethod` | `csrftoken`, `oldPassword`, `newPassword`, `confirmPassword` | `/setting/changePassword` 页隐藏域 |
| 改个人资料 | `POST /setting/updateUserSecurity` | `csrftoken`, `checkCode`, `userCompany`, `userPhone`, `userEmail`, `userAddress` | `/setting/personList` 页隐藏域 |
| 绑定运营商账号 | `POST /service/bind-operator` | — | **学校未启用**（页面直接显示「未启用运营商对接功能」，提交按钮 disabled） |

- 应答统一 `{state, message}`（`state == 'success'` 成功；失败时原因常在 `data`）。
  少数接口（`tooffline` / `unbindmac`）返回空体或纯文本 → App 侧按「写后重新拉数据对账」处理，不靠文案判成败。
- 改密码校验：旧密码必填；新密码 **6–16 位**、不能含空格；确认必须等于新密码。
- 微信充值 = 外部页 `https://self.jxufe.cn/WebPay/recharge?paytype=3&account=<学号>`（App 只带账号打开，不碰支付）。

## 5. App 侧落地（用户 2026-09-16 拍板）

> 「A. 校园网页第二段升级为真数据」+ 全量数据（含在线设备/账单/充值/办理记录/资费/上网密码）
> + 「连业务办理一起做（报停 / 复通 / 预约套餐 / 修改密码 / 绑定运营商）」

- 第二段 `NetworkServiceSection`（`lib/features/network_service/presentation/network_service_section.dart`）：
  账号概览（余额 / 套餐 / 计费方式 / 本周期时长流量 / 适用范围 / 上网账号 / 上网密码掩码+复制）
  + 在线设备（可强制下线）+ 近期上网记录 + 明细与业务入口（历史账单 / 充值明细 / 业务办理记录 /
  资费介绍 / 账号服务 / 账号设置 / 微信充值）。
- 子页：`network_records_screen.dart`（账单四页签）、`network_devices_screen.dart`（在线会话 + 已绑定设备）、
  `network_services_screen.dart`（账号服务 / 资费介绍 / 办理记录）、`network_profile_screen.dart`（资料 + 改密码）。
- 数据层：`NetworkServiceRemoteDataSource`（会话缓存 + 自动重登 + token 现取 + 全部读写接口），
  provider 见 `network_service_providers.dart`（`invalidateNetworkService` 整组失效做写后对账）。
- 敏感信息：上网密码**默认掩码**、身份证号只显示前 3 后 4；都不写日志。
- 未做：上网记录「导出 Excel」（`/bill/exportUserOnlineLog`）、在线充值（在线支付流程）。
