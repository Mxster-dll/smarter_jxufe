# 抓包指引 · 赛康精益小程序

目标：拿到小程序**登录请求 + 三类查询请求**的真实流量（URL、参数、headers、响应 JSON）。
产物：把导出文件放到 `reverse_engineering/saikang_tice/captures/`（该目录已在 .gitignore，不会误提交）。

---

## 0. 抓什么（场景清单）

按顺序操作，每个场景**至少成功跑一遍**即可，别反复刷：

| # | 场景 | 操作 | 我要从流量里找的东西 |
|---|---|---|---|
| S1 | 登录/启动 | 冷启动小程序（先杀掉后台），走完微信授权进首页 | 登录接口路径、请求头里 token 的名字和位置、返回的 token/用户信息结构 |
| S2 | 查自己的成绩 | 打开"我的成绩/体测成绩"类页面（含切换学年/学期如果有） | 成绩查询接口、请求参数（学号？年份？）、响应字段 |
| S3 | 查班级/年级 | 进入班级/年级列表 → 打开任意 2~3 个学生的成绩明细 | 列表接口（分页参数）、按学号或按人查明细的接口 |
| S4 | 统计/导出（若有） | 界面上有排名、统计、导出、评分标准之类，各点一次 | 附加接口，丰富字段字典 |

加分动作（可选，不强求）：
- 查询时在搜索框输入一个学号再搜一次 → 可看出"按学号单查"的接口形态
- 下拉"加载更多"一次 → 可看出分页参数（page/pageSize/offset…）

**注意**：抓包期间别去点支付、人脸、绑定类功能；只需以上查询链路。

## 1. 方案 A：本机代理（推荐给愿意让手机走电脑代理的人）

条件：手机和电脑在同一 WiFi/局域网，且电脑 8080 端口可达手机。

1. 电脑装 mitmproxy（或用已有 Fiddler/Charles）。
2. 启动：`mitmweb -p 8080`（网页界面，或 `mitmdump -w captures/sk.flow` 落盘）。
   弹防火墙授权时选"允许"（专用网络）。
3. 手机 WiFi 设置 → 代理 → 手动 → 填 `电脑IP:8080`（本机查 IP：`ipconfig`）。
4. 手机浏览器访问 `http://mitm.it` 按系统装证书：
   - **Android**：下载 CA 证书 → 设置里安装（"CA 证书"）。Android 7+ 提示风险属正常，选"仍安装"。
   - **iPhone**：下载描述文件 → 设置→通用→VPN与设备管理 安装 → 再进 设置→通用→关于本机→**证书信任设置** 打开完全信任（漏这步必失败）。
5. 验证：手机浏览器开个 http 网站能通 → 微信里进小程序，开始跑 S1~S4。
6. 结束：关手机代理 → 电脑导出。

导出格式任选：HAR（`File > Export` 或 mitmweb 右上角导出）、mitmproxy flow 文件、或直接贴 JSON 响应也行。

## 2. 方案 B：手机本地抓包 App（最省事，不需要电脑参与）

- **Android**：HttpCanary（小黄鸟）/ Reqable。装好后按 App 引导安装其证书（用户证书即可，一般无需 root），点开始抓包（VPN 模式），切到微信跑 S1~S4，停止后**导出为 HAR/Json**。
- **iPhone**：Stream / Reqable。按引导装描述文件 + 证书信任，同上。

导出文件用微信/QQ 传到电脑，丢进 `captures/`。

## 3. 方案 C：PC 微信（备选，需在这台电脑装 PC 微信）

电脑装 PC 微信 → Fiddler/mitmproxy 开解密 HTTPS → 系统级证书信任 → PC 微信里搜索并打开小程序 → 跑场景。
优点：全程在这台机器上，产物直接落盘；缺点：需要装微信 + 证书装到 Windows 信任库。

## 4. 遇到问题自查表

| 现象 | 原因与对策 |
|---|---|
| 抓不到任何微信流量 | 代理没生效：确认手机代理开着、微信完全重启过（要杀掉后台） |
| 只有 `CONNECT` 没有内容 | HTTPS 没解密：证书没装 / iPhone 漏了"证书信任设置"那步 |
| 小程序提示"网络异常/无法连接" | 证书不被信任：重装证书并重启微信；或该域名证书钉扎（少见），换方案 B/C |
| 能抓首页但登录后白屏/报错 | 正常现象的一部分——把报错瞬间的请求也留档，可能正是登录接口在报错 |
| 流量太多找不到目标 | 顶部筛选域名，找**非微信官方域名**（`wx.*`、`qq.com` 都是微信自己的，忽略）；业务域名通常像 `api.xxx.com` 之类 |
| 不确定抓全没有 | 每个场景结束后在工具里搜索"score/student/login/grade/class"关键词核对 |
