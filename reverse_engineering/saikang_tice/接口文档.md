## 1. 核心查询接口（App 只需这一个）

### POST /src/StuSpace/queryStuResult.php

参数（form-urlencoded）：

| 参数 | 必填 | 说明 |
|---|---|---|
| stuNum | ✓ | 学号，如 `0252513` |
| stuSchool | ✓ | 学校全名，如 `江西财经大学`（URL 编码） |
| StartTestDate | ✓ | 学年学期窗口内**任意日期**（YYYY-MM-DD）。实测：2025-09-01 与 2025-11-04 等价；2025-06-01 / 2026-03-01 → 无记录。缺失 → "该生成绩尚未上传(含免测)" |
| openid | ✗ | **实测传垃圾值照样成功**，随便填（如固定占位） |
| nickName / userUrl | ✗ | 装饰参数，小程序传 `登录` / `../../static/img/loginIcon.png`，可省 |

成功响应（result=1）：
```json
{"result":"1","message":"成功","data":{
  "stuResult":[{
    "year":2025,
    "Result":{
      "whScore":   {"score":80,"testItem":"身高体重","result":"17.7","testclass":"良好"},
      "FHLScore":  {"score":80,"testItem":"肺活量","result":"4522","testclass":"良好"},
      "RUN50Score":{"score":74,"testItem":"50米跑","result":"7.6","testclass":"及格"},
      "LDTScore":  {"score":62,"testItem":"立定跳远","result":"215.5","testclass":"及格"},
      "ZWTScore":  {"score":0,"testItem":"坐位体前屈","result":"-2.1","testclass":"不及格"},
      "RUNScore":  {"score":78,"testItem":"耐力跑","result":"3'47''","testclass":"及格"},
      "YTYWScore": {"score":72,"testItem":"引体向上","result":"13","testclass":"及格"}},
    "totalResult":{"totalScore":67.8,"totalClass":"及格"}}],
  "stuInfo":{"stuNum":"0252513","stuName":"陈**","stuSex":"男",
             "gradeNum":"2025_40",
             "deptName":"计算机与人工智能学院（格里菲斯数智学院）、财经大数据教育部工程研究中心（培育）"}}}
```

字段说明：
- `stuResult` 数组：每元素一年成绩；`Result` 键为**项目代码**，固定 7 项（男生实测）：
  `whScore` 身高体重 / `FHLScore` 肺活量 / `RUN50Score` 50米跑 / `LDTScore` 立定跳远 / `ZWTScore` 坐位体前屈 / `RUNScore` 耐力跑(男1000m/女800m) / `YTYWScore` 引体向上(男)。女生第 7 项应为仰卧起坐（键名待实测，推测 `YQWScore` 一类；男生样例未覆盖）
- 各项目对象：`score` 数值 / `testItem` 名称 / `result` 原始成绩(字符串) / `testclass` 单项等级（良好/及格/不及格/优秀/空）；个别项还带空 `class` 键
- `testclass` 语义：优秀/良好/及格/不及格；`totalClass` 同
- `totalScore` 可能是小数（67.8）
- 免测/未上传（result=0）：`{"result":"0","message":"该生成绩尚未上传(含免测)","data":null}`
- 学号不存在/姓名不符时的报错消息未实测（后续补）

**分项键名跨性别/跨年份的完整全集待实测补充**（女生仰卧起坐键、跨 2024 老生多年度返回形态）。

## 2. 登录 / 绑定族接口（App 不需要，记录备用）

| 接口 | 请求 | 响应示例 | 用途 |
|---|---|---|---|
| GET /wx_sessionKey.php | `?js_code=<微信code>&grant_type=authorization_code` | `odAkc5Nn…`（纯 openid 文本） | 微信环境换 openid |
| POST /wx_SchoolName.php | `{}` | `请选择学校名称\|郑州升达…\|江西财经大学\|…`（`\|` 分隔） | 学校名单 |
| POST /wx_getUserInfo.php | `openId=…` | 已绑定 `0252513\|1\|江西财经大学\|odAkc…\|陈**`；未绑定 `N\|您还没有登录` | 当前绑定态 |
| POST /wx_bind.php | `stuNum=…&schoolName=…&openId=…` | `Y\|绑定成功` | 绑定学号 |
| POST /wx_RelieveBind.php | `openId=…` | `Y\|解绑成功` | 解绑 |

小程序 UI 的"查多人 = 反复解绑/重绑"仅是前端流程；后端 `queryStuResult` 不校验绑定，**App 直接按学号查即可，无需绑定**。
