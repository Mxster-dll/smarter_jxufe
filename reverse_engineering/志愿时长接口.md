# 志愿服务时长（综合管理平台 SSP）接口与口径

站点：`http://ssp.jxufe.edu.cn`，会话 = SSP 自己的 `JSESSIONID`（换取链见
`comprehensive_login.http`，代码在 `lib/features/comprehensive_service/data/`）。
本文档记录 **2026-09-16** 补齐「每个志愿服务的时间」与「本学年志愿时长」时逆向到的内容。

## 1. 列表页没有时间列（关键事实）

`GET /admin/tzz/StuVolWork/stu_list.html`
（`Cookie: JSESSIONID=<ssp 会话>`，`Referer: http://ssp.jxufe.edu.cn/admin/common/main.html`）

页面标题「学生活动时长统计」，表格 `#listTable` 实测只有 **10 列**：

```
序号 | 活动名称 | 发起人 | 负责人 | 活动所属部门/学院 | 活动类别 | 认定时长 | 申请状态 | 认定状态 | 操作
```

- **没有任何时间列**（全页 `活动时间` / `开始时间` / `结束时间` 命中 0 次）；
- 筛选项只有「活动名称」模糊搜索 + 分页（`listForm` POST 回 `stu_list.html`），**没有学年筛选**；
- 页面顶部文案 = 分档规则：「累计时长 20 小时及以上 1 分，30 小时及以上 1.5 分，50 小时及以上 2 分，100 小时及以上 4 分」；
- 「操作」列的链接是内联 JS：`<a href="javascript:;detail(<id>,'<type>')">详情</a>`。

页面内联 `function detail(id,type)` 的 switch 原文给出 4 个模块路径：

| type | 路径 |
|---|---|
| `0` | `/admin/tzz/DQXNVolWork/apply_one_detail.html`（当前学年志愿工作） |
| `1` | `/admin/tzz/DektVolActivitiesXw/apply_one_detail.html`（校级活动） |
| `2` | `/admin/tzz/HSJVolWork/apply_one_detail.html`（寒暑假） |
| `3` | `/admin/tzz/DektVolActivitiesZyfw/apply_one_detail.html`（志愿服务） |

## 2. 活动时间在「详情」页

`GET /admin/tzz/DQXNVolWork/apply_one_detail.html?id=<detailId>&type=<type>`
（同一会话；实测缺 `id`/`type` 之一时会返回「出错了」页或另一张列表页）

标题「短期校内活动申报详情」，字段（只读输入框）：

| 字段 | 元素 id | 实测值（示例） |
|---|---|---|
| 发起人 | `#publishAdminName` | 某同学（脱敏：某同学） |
| 负责人 | `#responseAdminName` | 同上 |
| 活动所属部门 | `#orgName` | 社会与人文学院 |
| 开始时间 | `#startTime` | `2026-05-26` |
| 结束时间 | `#endTime` | `2026-05-26` |

⚠ **`id="startTime"` 在页面里出现两次**：真实开始时间框（有值，在前）与**备注输入框**（空值，在后）
→ 解析必须只认**第一个 `<input>`**（`anti_corruption/volunteer_detail_parser.dart` 的
`parseVolunteerActivityTime`），且只能在 `<input>` 标签里取值（备注那个也是 input，但顺序在后；
另有 `<textarea>` 的情况同样要排除）。

## 3. 另一条含日期的通路：认定登记表 Word

`GET /admin/tzz/StuVolWork/downloadInfo.do`（「下载时长认定登记表」按钮同款）

- OOXML（`PK\x03\x04`），实测 14961 B；`word/document.xml` 内是
  「江西财经大学青年志愿者志愿服务时长认定登记表」两栏表格：
  表头 `序号 | 活动名称 | 认定日期 | 所属类别 | 时长`（左栏 5 行 + 右栏续排）、
  末尾 `志愿服务总时长 24.0小时`、`数据导出时间：2026年09月16日`。
- **认定日期是「认定」日期**（比活动开始晚几天，例：活动 2026-05-26 → 认定 2026-05-28），
  与详情页的活动起止时间**不是同一口径** → App 显示「活动时间」用详情页，
  登记表只作为导出证明（现状：原样透传下载，不解析 Word）。
- 表头行还含个人身份信息（学院/专业/姓名/学号）→ 若要解析 Word，注意别把身份信息带进界面/日志。

### 本学年口径（load-bearing）

**「本学年」= 当下教学学年**，取 `currentSchoolTerm(now, terms: offlineSemesterTerms).xn`
（与课表 / 校历 / 今日课程同一口径，见 AGENTS §9），窗口 `[xn]-09-01 ~ [xn+1]-08-31`。

- 2026-09-16 实测：`xn = 2026`（校历 261 = 2026-09-07 ~ 2027-01-16）→ 本学年 = 2026-2027；
  该账号 5 条记录活动日期 2025-10-22 ~ 2026-05-26 **全属上一学年** →
  `total = 24.0`（卡片主数值）、`本学年 = 0h`、`previousYear = 24.0`（胶囊 tooltip 里对照显示）。
- ⚠ **不要用综测模块的 `zcDefaultYear`**：那是**测评学年**（9 月起评刚结束的那一学年，
  2026-09 时给 2025-2026），2026-09-16 首版误用它 → 卡片标着「本学年」却显示上学年的 24 h，
  用户当即报「现在实际显示的志愿时长是上学年的」。
- 一条活动都取不到日期时 `yearKnown = false` → 胶囊显示 `本学年 —`（**不要显示 0**，
  否则「取不到日期」会被误读成「本学年没有志愿时长」）。
