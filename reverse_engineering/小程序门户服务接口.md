# 智慧江财小程序 · 门户服务接口（侦察法）

> 2026-09-16 实测。**先说结论：门户式（低代码）小程序的每个服务都在后台有条目记录，条目里带真实地址 —— 拿到平台 GUID 就能把全部门店与入口列出来，不必抓包。**

## 0. 认证前提

- `platformUsername` = **平台 GUID**（36 位 UUID 形如 `00000000-0000-4000-8000-000000000000`）。
  App 侧存在 Hive `wxPlatform.guid`（设置页「获取平台标识」向导写入；`lib/features/school_calendar/data/providers/wxcal_providers.dart` 的 `wxGuidProvider` 是唯一读取口径）。
  离线读法：`app_data/wxplatform.hive` 二进制里 latin-1 解码后正则 36 位 UUID。
- 所有请求必须带：
  - `Referer: https://servicewechat.com/wx70c0beda0bb7b021/143/page-frame.html`
  - 浏览器 UA（App 内用 `deviceProfileRepositoryProvider.userAgent`）
- 两个域：门户管理域 `https://wxcourse.jxufe.edu.cn/platForm`（GUID 相关），业务 H5 域 `https://wxcourse.jxufe.cn`（`reqUrl` 同域；证书/OID 表那些是插件自带，与本服务无关）。

## 2. 单个服务元信息（含加密账号与带签名入口）

```
GET https://wxcourse.jxufe.edu.cn/platForm/api/littleProgram/application/checkAppAuth?appid=<appId>&platformUsername=<GUID>
→ {"code":200,"success":true,"message":"可以访问","result":{
     "name":"本科生成绩单","memo":"该应用提供了本科生通过邮箱发送本科生成绩单的服务",
     "typeC":"H5","isCredible":"1","useVersion":"2.0",
     "username":"AAAAAAAAAAAAAAAAAAAAAA==",      ← 加密账号 enc（H5 的 ?userId=）
     "pageUrl":"https://wxcourse.jxufe.cn/1575336885141//login/verifyByWeChat?cardinfo=…&sno=0000000&openId=…",
     "jssdkUrl":"https://wxcourse.jxufe.cn/dir/usr/local/mobilePlatform/file/jssdk/V1.8/h5_jssdk_V1.8.js"}}
```

- `code` 用 **200**（不是 1）判成功；失败时 `message` 是「没有访问权限」之类。
- `username`（enc）**同一账号对不同 appid 可能相同**（成绩单与在校证明实测都是 `AAAAAAAAAAAAAAAAAAAAAA==`）。
- ⚠ enc 里含 `+` / `=`：当表单字段提交时必须百分号编码（H5 自己写了 `encodeURIComponent`）；当 query 参数提交时同理由 Dio/requests 自动处理。**裸拼进 form body 会把 `+` 变成空格 → 服务端解出来是错的账号。**

## 3. 其它常用门户接口（实测可用）

| 接口 | 作用 |
|---|---|
| `GET /api/littleProgram/login/getUserInfo?platformUsername=<GUID>` | 平台账号信息（`email` 字段 = 门户绑定邮箱，本账号为 null） |
| `GET /api/littleProgram/organizationUser/getUserInfoData?platformUsername=<GUID>` | 校内身份：`user_id`(= 学号)、`sno`、`cnname`、`classNo`、`dept_id`、`caption`（学院） |
| `GET /api/wx/email/getPwd?username=<GUID>` | 学生邮箱**账号 + 初始密码**（见 `我的邮箱接口.md`） |
| `GET /api/third/email/getNoReadNums?username=<user_id>` | 邮箱未读邮件数（第三方代理） |
| `GET/POST /api/littleProgram/login/{getSmsCode,validateSmsCode,bindEmail}` | 手机验证码 + 绑定/更换门户邮箱（**写操作**） |
