# 我的邮箱接口（小程序「我的邮箱」）

> 2026-09-16 实测。小程序里**「我的邮箱」本身是跳独立小程序**（appId `wx0bc2c17d023b213d`，
> 条目 url = `/pages/frame/frame?appid=wx0bc2c17d023b213d`）；主包里与邮箱相关的另有三个原生页：
> `pages/center/email/view`（**绑定邮箱**，标题就是这个）、`pages/center/amendEmail/amendEmail`（**更换邮箱**）、
> `pages/modules/app/detail/emailPasswd/view`（**邮箱密码**：`email` + `pwd` + 掩码/眼睛切换 + 复制）。

App 侧只复刻门户能拿到的账号信息（用户 2026-09-16 裁定：「只有查看账号、初始密码、复制邮箱、
复制初始密码」）。

## 1. 学生邮箱账号 + 初始密码（已实现）

```
GET https://wxcourse.jxufe.cn/platForm/api/wx/email/getPwd?username=<GUID>
→ {"code":1,"success":true,"message":null,
   "result":{"email":"2000000000@stu.jxufe.edu.cn","pwd":"zAacW6yCq4"}}
```

- `username` = **平台 GUID 本身**（不需要 checkAppAuth 换 enc；与网费/成绩单不同！）。
- 邮箱地址规则：**10 位学号 @ stu.jxufe.edu.cn**（本账号 `2000000000@stu.jxufe.edu.cn`）。
  ⚠ 与学籍 `serialNo`（12 位，如 `201600035929`）**不是一回事** —— 别拿它拼邮箱。
- `pwd` = 学校邮件系统下发的**初始密码**（本账号 10 位）；用户自行改过密码后这里仍是初始值。
- 失败态：`success=false` + `message`（会直接显示给用户）。

## 2. 其它邮箱相关接口（App 侧未采用）

| 接口 | 作用 | 为什么没用 |
|---|---|---|
| `GET /platForm/api/third/email/getNoReadNums?username=<user_id>` | 邮箱未读邮件数（门户首页给「我的邮箱」磁贴挂角标用的；`user_id` 取自 `organizationUser/getUserInfoData`） | 用户裁定只做账号信息 |
| `GET/POST /platForm/api/littleProgram/login/getSmsCode` → `validateSmsCode` → `bindEmail` | 绑定 / 更换**门户账号邮箱**（短信验证码校验；`platformUsername` + `email`） | 写操作，用户裁定不做 |
| `GET /platForm/api/littleProgram/login/getUserInfo` 的 `email` / `emailWithXing` | 门户**绑定邮箱**（本账号 `null` = 未绑定） | 同上 |
| `GET /platForm/api/wx/email/getPwd` 的密码明文 | 小程序「邮箱密码」页展示口径一致：默认掩码、点眼睛显示、可复制 | 已实现（`'*' × 长度` 掩码） |

## 3. 邮箱 Web 入口不可达（实测）

| 主机 | 结果 |
|---|---|
| `stu.jxufe.edu.cn` | 993 / 143 / 443 / 25 **全部 timeout**（能解析，连不上） |
| `mail.jxufe.edu.cn` | 443/993/143 timeout，**仅 :25 TCP 可连** |
| `mail.stu.jxufe.edu.cn`、`webmail.jxufe.edu.cn` | 不解析（getaddrinfo failed） |
| `exmail.qq.com` | 200（腾讯企业邮通用入口，非本校前端） |

→ 邮箱界面**仅校园网/VPN 可达**，App 不内嵌邮箱、也不做 IMAP 取信（见 `本科生成绩单接口.md` §3）。

## 4. App 侧实现

- 领域：`lib/features/my_mail/domain/student_mailbox.dart`
  （`StudentMailbox{email,password}` + `myMailMaskPassword`（`'*'×长度`）+ `myMailStudentAddress(学号)`）
- 数据：`lib/features/my_mail/data/datasources/my_mail_remote_datasource.dart`
  （`getPwdPath = '/platForm/api/wx/email/getPwd'`，DioException → `MyMailApiException`）
- provider：`lib/features/my_mail/data/providers/my_mail_providers.dart`
  （`myMailboxProvider` + `kMyMailNeedGuid` + `myMailNeedsGuid`；GUID 复用 `wxGuidProvider`）
- 界面：`lib/features/my_mail/presentation/my_mail_screen.dart`（卡片：邮箱账号 + 初始密码，
  两个复制按钮；密码默认掩码，掩码下复制的是真值；未配置 GUID → 错误卡上给「去获取平台标识」）
- 入口：首页服务目录 `我的邮箱`（`FeaturePalette.myMail`）。
