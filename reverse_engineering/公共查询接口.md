# 教务「公共查询」课表接口（2026-09-14 全量实测 · 四类课表已打通）

> 目标：实现「按教师 / 按班级 / 按教室 / 按课程 查课表」，并在此基础上做**多班对照找无课时间**。
> 本文只写**实测确认**的内容；未确认的一律进 §9。客户端落点见 §8。

## 0. 一句话结论

「公共查询」= 菜单码 **`SB`**（9 个功能页，页面在 `/kbbp/`，访客版 `/public/` **带验证码不可用**）。
数据端点 = **`POST /kbbp/dykb.GS1.jsp?kblx=<kckb|jskb|bjkb|jsikb>`**，
请求体 = 整张 `ActionForm` 的 **urlencoded** 表单，响应 = **GBK HTML 报表**。
本仓库已实现 **课程 / 教师 / 班级 / 教室** 四类（选择器 + 报表 + 网格 + 多班对照）。

## 2. ★ 传输层三铁律（照直觉写必错）

1. **报告端点只认 `application/x-www-form-urlencoded`**。`dykb.GS1.jsp` 是**普通 JSP**，
   `request.getParameter()` **不解析 multipart**：用 dio 的 `FormData`（multipart）提交时，
   服务端**一个参数都收不到** → 报表以「无过滤条件」跑一遍 → 恒返回
   `没有检索到记录！`（HTTP 200，2652 字节）。
   **对策**：手工拼表单体（`k=v&k=v`，`Uri.encodeQueryComponent` 编码），
   见 `period_table_remote_datasource.dart` 与 `PublicQueryRemoteDataSource.encodeForm`。
   > 对照：`/frame/droplist/*.action`（Struts2）与 `/taglib/*.jsp` 能吃 multipart，
   > 所以**只有报告端点在 multipart 下静默空结果**——这正是本任务卡了最久的坑。
2. **编码三分**：报告 `dykb.*.jsp` = **GBK**（`Content-Type` 不带 charset → dio 的
   `responseDecoder` 会走 `utf8.decode` 抛 `FormatException: Missing extension byte`，
   必须 `ResponseType.bytes` + `fast_gbk`）；下拉列表 JSON、选择器 XML、`SetRootPath*.jsp` = **UTF-8**。
3. **大树响应要放宽超时**：教室课表不带楼房过滤时一次返回整个校区全部教室（实测 **1731809 字节**），
   默认 20s `receiveTimeout` 会 `DioException [receive timeout]` → 数据源固定 150s。

## 3. 会话与探测方法

- 动态页面/接口必须带有效 `JSESSIONID`，否则统一返回 **547 字节**的
  `<script>alert('温馨提示：凭证已失效，请重新登录!')`；静态资源（`/js/*`、`/custom/js/*`）**不受限**。
- 只有 App 自己的 Dart/Dio 会话能拿数据；python/curl 同 token 一律 547（按客户端指纹拦）。
- **探针必须自带续期**（不要依赖 `app_data/imsauth.hive` 里的 token 是否新鲜）：
  ```dart
  final repo = await ProviderContainer().read(authRepositoryForAccountProvider(账号).future);
  final redirect = (await repo.getImsRedirectInfo()).fold((f) => throw StateError('$f'), (v) => v);
  final jid = await fetchAndActivateJsessionId(imsDio: dio, redirectUrl: redirect.$1, gid: redirect.$2);
  ```
- headless 无法自己登录（`detectMfa` 恒 `needMfa=true`，MFA 处理器只由 UI 设置）；
  但 `getImsRedirectInfo()` 在 **TGC 有效**时会静默换票成功 —— 上述探针因此可用。
- 探针的 Hive 目录**每个探针用独立临时目录**并先删 `*.lock`：并发/被杀进程会留下
  `PathAccessException: lock failed, path = '…\auth.lock'`（errno 33）。
- 跑测试前 `Remove-Item build\unit_test_assets -Recurse -Force`；**不要与运行中的 `flutter run` 同时跑**（构建目录争用，曾把运行会话搞成 `Lost connection to device.`）。

## 7. 报表 HTML 结构与解析要点

```
<div group="group" …>                       ← 描述块：若干 <div style="float:left…">标签：值</div>
  <div style="float:left;width:27%;…">院(系)/部：会计学院</div>
  <div style="float:left;width:33%;…">班级：26会计学S1班[80]</div>
</div>
<!-- 报表区 -->
<table class='table' id='mytable0' name='mytable0'>   ← 一个 mytableN = 一个对象（班/教师/教室/课程）
  <thead>… <td class='td0'>星期一</td> …</thead>
  <tbody>
    <tr>
      <td class='td1' rowspan='2'><b>上<br>午</b></td>          ← 半日块
      <td class='td1' style="font-size: 10px"><b>1-2节</b></td> ← 大节行标签
      <td class='td' title="会计学原理&ensp;4&ensp;周天杭&ensp;[2-17]周&ensp;1-2节&ensp;蛟一教1101&ensp;蛟桥园校区&#13;">
        <div class='div1' onclick='labClick(this)' id='011'> … </div></td>
```

解析口径（`parsePublicTimetableReport`）：

1. **`div1` 的 id = `<表序号><星期><大节序号>`**（表序号 ≥10 时为两位，如 `1011` = 第 10 张表 / 周一 / 第 1 大节）
   → **星期与大节从 id 反推**，不要按行列计数（合并单元格会让列号错位）。
2. **大节 → 实际节次用行标签还原**：江财当前是 `1-2 / 3-5 / 6-7 / 8-9 / 10-12` 五档，
   别硬编码「每大节 2 小节」。
3. 格子文本 = `&ensp;` 分隔的片段（`title` 属性与 `div` 文本一致，取 `title` 更干净）；
   `&amp;ensp;` 的转义形态也要认。片段语义随类别变化：
   - 班级课表：`课程名 ‖ 学分 ‖ 教师 ‖ [2-17]周 ‖ 1-2节 ‖ 教室 ‖ 校区`
   - 教师课表：`课程名 ‖ 学分 ‖ 总学时 ‖ … ‖ 考查 ‖ 必修课 ‖ [2-17]周 ‖ 1-2节 ‖ 教室 ‖ 校区 ‖ 班级`
   - 课程课表：`教师 ‖ [2-11]周 ‖ 1-2节 ‖ 班级 ‖ 教室 ‖ 校区`
   - 教室课表：`课程名 ‖ 学分 ‖ 教师 ‖ [2-9]周 ‖ 1-2节 ‖ …`
4. 描述块标签按类别不同（班级：`院(系)/部 / 年级 / 专业 / 班级`；教师：`部门 / 教师 / 职称`；
   教室：`校区 / 楼房 / 教室类型 / 教室`；课程：`承担单位 / 课程 / 总学时`）。
   **对象名要精确匹配标签**：`教室类型` 也以「教室」开头，用前缀匹配会取成「设计室」。
5. 一次响应可能含**几十上百张表**（教室课表），客户端要限流展示。
6. 表尾 `备注N[星期第X大节]：…` / `注N：…` 是补充说明（如多班合上的体育课）。
