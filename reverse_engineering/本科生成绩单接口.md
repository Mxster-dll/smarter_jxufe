# 本科生成绩单 / 在校证明接口（小程序「本科生成绩单」）

> 2026-09-16 实测。对应小程序「教学」模块里的**本科生成绩单**（与**本科生在校证明**），
> H5 入口 = `https://wxcourse.jxufe.cn/jxufeLayuiApp/certificate/undergraduate/scoreIndex.html?v=1`
> （在校证明 = 同目录 `proveIndex.html?v=1`）。官方口径见教务处 2025-05-20 通知：
> **学生在小程序里选报表类型 → 填邮箱 → 系统把加盖电子签章的 PDF 发到邮箱**，PDF 可在
> 学信网验证（`https://www.chsi.com.cn/cjdyz/index`）。

## 1. 认证链

与网费同款（见 `小程序门户服务接口.md` §2）：

```
GUID --checkAppAuth(appid=1741570971384)--> enc  (= H5 的 URL 参数 ?userId=)
```

- 成绩单 `appid = 1741570971384`；在校证明 `appid = 1741570790414`（**enc 相同**）。
- `checkAppAuth` 的 `memo` 原文：`该应用提供了本科生通过邮箱发送本科生成绩单的服务`，
  `isCredible: "1"`（可信电子成绩单）。
- ⚠ **enc 提交表单时必须百分号编码**（`+`→`%2B`、`=`→`%3D`）：H5 里写死了
  `if(username.indexOf("=")!=-1||username.indexOf("+")!=-1) username=encodeURIComponent(username)`。
  Dio 用 `data:{}` + `Headers.formUrlEncodedContentType` 与之一致（守卫见 `test/transcript_test.dart`）。

## 2. 两个接口

### 2.1 查可申请的报表类型

```
POST https://wxcourse.jxufe.cn/layuiApp/score/verifySecondMajor
Content-Type: application/x-www-form-urlencoded
userId=<enc>

→ {"message":",1","status":true}      # 本账号实测：只有主修
→ {"message":",1,2","status":true}    # 有主修 + 辅修
```

`message` **首位无意义**（H5 用 `message.substring(1)` 去掉），其余按 `,` 切：

| token | 生成的选项（courseId → 文案） |
|---|---|
| `1` | `1` 主修成绩单（中）、`11` 主修成绩单（英） |
| `2` | `2` 辅修成绩单（中）、`22` 辅修成绩单（英） |

`status=false` 时 `message` 是错误文案（如「学号不存在」）。

### 2.2 发送成绩单到邮箱（**唯一的取件方式**）

```
POST https://wxcourse.jxufe.cn/layuiApp/score/bkscj
Content-Type: application/x-www-form-urlencoded
userId=<enc>&email=<邮箱>&courseId=<1|11|2|22>

→ {"status":true,"message":"…提示语…"}
```

- `status=false` → `message` 为失败原因。
- **没有下载接口**：PDF 只发邮箱。信封由教务处邮件系统发出（加盖电子签章）。
- 在校证明（同构，字段只有 userId + email）：
  `POST https://wxcourse.jxufe.cn/layuiApp/studentCertificate/bks`
  （App 侧本轮**未**实现，用户 2026-09-16 裁定「只做成绩单」。）

## 3. 为什么 App 不能「一键下载 PDF」

- 官方无下载接口（见上）。
- 学生邮箱服务（`stu.jxufe.edu.cn`，账号形如 `2000000000@stu.jxufe.edu.cn`，取自邮箱接口）
  在本机网络**端口 993/143/443/25 全部 timeout**（仅校园网/VPN 可达），so IMAP 代收方案不可行；
  `mail.jxufe.edu.cn` 只有 `:25` TCP 通。`exmail.qq.com` 可达但那不是本校邮件前端。
- 结论（用户裁定）：**App 只做「选类型 + 填邮箱 + 发送」，PDF 由用户自己到邮箱下载**。
