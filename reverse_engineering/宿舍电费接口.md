## 关键约定

- **Base**：`https://wxcourse.jxufe.cn/electricity_charges`（注意 .cn；另有新体系
  `https://bianminjf.jxufe.edu.cn` 为 hydropower 水电账单缴费，与本查询无关）。
- **Referer 必须带**（nginx 裸请求 403）：`https://servicewechat.com/wx70c0beda0bb7b021/143/page-frame.html`。
- 无鉴权 Cookie / token；绑定表按「学号 ↔ roomId」维护（弱校验，任意学号可绑任意房间）。
- 响应 UTF-8 JSON：`{code, message, success, result}`，code==1 成功。
- **roomId 是内部主键**（如 6499），展示名有两套：`name`（如 05602）、`roomManuCode`（如 12464，
  即 findRoomBalance 返回的 roomNo）。只能经级联目录获取。

## 余额查询（本页核心）

```
GET /electricity_charges/api/charges/findRoomBalance?username=<学号>&roomId=<内部id>
200 {"code":1,"message":"成功","success":true,
     "result":{"unit":"kWh","roomNo":"12464","balance":"194.47"}}
```
- 参数必须成对：`roomId` 须存在于房间表；`username` 须已绑定该 roomId。
- 失败：无 username →「房间信息不存在！」；假学号+真房间 →「未绑定该房间！」；
  真学号+假房间 →「房间信息不存在！」。
- 测试账号 2000000000 已绑定麦庐校区 北区5栋 6层 05602（roomId=6499, roomManuCode=12464）。

## 宿舍级联目录（免鉴权）

```
GET /room/findCampusList                 → result:[{id,campus}]  1=蛟桥 2=麦庐 3=枫林
GET /room/findBuildingList?campusId=N    → result:[{id,name}]    麦庐含「北区5栋」id=36
GET /room/findFloorListByBuilding?buildingId=N → result:[{id,name}] 1层..（北区5栋 6层 id=215）
GET /room/findRoomListByFloor?floorId=N  → result:[{id,name,roomManuCode}]
   房间 id=6499 name=05602 roomManuCode=12464（北区5栋 6层）
```
- 蛟桥 12 栋（学生公寓楼）= building 40，房间 id 从 6972 起（roomManuCode 12-401…），
  与 6499 分属不同表段 —— 找房间必须按校区→楼→层→房逐级下钻。

## 绑定

```
GET /room/bindUserRoom?username=<学号>&roomId=<房间id> → {success:true,...}
```
- 小程序「绑定房间」页（dfcz_new/roomBind）即此接口；无需平台 userId。
- `GET /room/findUserBindedRoom?username&userId` 需平台 userId（解密 uid），App 不可用；
  `POST /interface/api/interface/queryBoundRooms`（JSON body）是 dfcz 域另一张表
  （该账号为空），已废弃/无用。
- 充值/缴费走 H5 webview（openId/userId 平台参数），App 不做。
