# 第二课堂 · 学科竞赛接口（申请 / 公示）

> 实测时间：2026-09-16 · 平台：`http://ssp.jxufe.edu.cn`（综合管理服务平台 · 团委「第二课堂」模块）
> 抓包账号：`2000000000`（会话 = SSP 的 `JSESSIONID`，与「第二课堂学分 / 志愿时长」同一套）
> App 实现：`lib/features/comprehensive_service/`（`competition_*`）

## 0. 一句话

官网菜单里「**学科竞赛申请**」「**学科竞赛公示**」两个页面都挂在
`/admin/tzz/dektSubjectGame/` 下：申请是「我的申请列表 + 新增表单（选比赛 / 选奖项 / 个人或团队 / 传证书图片）」，
公示是「全校已公示获奖列表（可按学号 / 姓名 / 班级搜）+ 详情」。
**列表全是服务端渲染的 `table#listTable`，分页靠请求参数 `pageNumber`；只有奖项是 JSON。**

统一请求头：

```
Cookie: JSESSIONID=<ssp 会话>
Referer: http://ssp.jxufe.edu.cn/admin/tzz/dektSubjectGame/apply_list.html   （toAdd/upload 用 …/toAdd.html）
X-Requested-With: XMLHttpRequest        （.do 的 JSON 接口）
```

会话失效 = 3xx 或 200 的登录页 HTML（含 `authFailure` / `/sso/login`）→ 走统一认证刷新后重试一次。

## 2. 分页与筛选口径（**最容易踩的坑**）

- 分页参数名 = `pageNumber`（1 起），每页 20 条；总页数在分页条 `<ul class="pagination">` 里以
  `javascript: $.pageSkip(N)` 出现 → 取最大值即可（公示 13 页、比赛目录 208 页）。
- **第 1 页 / 换筛选条件时必须带 `pageInit=yes`**：不带的话**筛选参数被服务端忽略**（实测
  `search_like_gameName=蓝桥杯&pageNumber=1` 返回 0 条，加 `pageInit=yes` 才有结果）。
- **翻第 N 页要重复带上同一批筛选参数，且不能带 `pageInit`**：带 `pageInit=yes` 会被强制重置回第 1 页；
  只带 `pageNumber` 则是「无筛选的全局第 N 页」。
  App 里的唯一实现 = `competitionPageRequestParams({page, pageSize, filters})`。
- 官网前端靠 Cookie 里的 `listQuery` 记住条件，客户端没有 Cookie jar → **每次请求都重发筛选参数**。

## 3. 各页面字段位置（解析口径）

### 3.1 `apply_list.html`（10 列）

`0 序号 / 1 比赛年份 / 2 学号 / 3 申请人姓名 / 4 比赛名称 / 5 类型 / 6 申请时间 / 7 附件 / 8 审批状态 / 9 操作`

- 行 id：操作列里 `showDelete(<id>)`（或 `showDetail(<id>,'look','个人')`）。
- 审批状态原文：`未审批` / `通过` / `未通过`。
- 第 7 列（附件）里塞了一段 inline `<script>`（popover 初始化），取文本要过滤。

### 3.2 `gs_list.html`（9 列）

`0 序号 / 1 学号 / 2 申请人姓名 / 3 学院 / 4 班级 / 5 比赛名称 / 6 类型 / 7 时间 / 8 操作`

### 3.3 `find_game.do`（6 列）

`0 选择框 / 1 比赛年份 / 2 比赛名称【赛别】 / 3 校内对接单位 / 4 比赛时间 / 5 比赛网址`

- 第 0 列是 `<input type="radio" name="ids" value="<gameId>" data-level="国赛">`
  → **gameId 与赛别都在这个 radio 上**（名称里的【…】是排版，赛别以 `data-level` 为准）。

### 3.4 `find_student.do`（5 列）

`0 选择框 / 1 学号 / 2 姓名 / 3 学院 / 4 班级`

- ⚠ radio 的 `value` 是**内部成员 id**（如 `350377`），**不是学号**（学号在第 1 列，如 `826200545`）。
  团队 `team` 字段要的是**内部 id**（见 §4）。

### 3.5 详情页（`detail.html` / `xd_detail.html`）

结构 = `<label>标题</label>` + 紧跟的 `<input readonly value="…">` / `<select disabled>` / `<textarea readonly>`：

| 页面 | 字段 |
|---|---|
| 申请详情 | 比赛名称 / 比赛类别 / 比赛级别 / 比赛年份 / 比赛时间 / 比赛网址 / 校内对接单位 / 主办单位 / 项目描述 / 附件 |
| 公示详情（**个人**） | 申请人姓名 / 学号 / 行政班级 / 比赛名称 / 比赛时间 / 比赛网址 / 学生提交的奖项 / 最终获得奖项 / 个人得分 / 意见 |
| 公示详情（**团队**） | **没有申请人字段**；改出 `团队成员列表` 表格（排名 / 学号 / 姓名 / 学院 / 班级 / 得分） |

- `select` 的当前值只能认带 `selected` 的 option；还没评奖时会没有 `selected`（首选项 value 为空）
  → 解析为空串（别把首选项文字「请设置奖项 / 无」当成结果）。
- 附件地址在 `onclick="openImg_lx('<url>','jpg','[…]')"` 里。

#### 3.5.1 获奖等级只能从详情取（公示列表**没有**这一列）

`gs_list.html` 的 9 列里没有奖项 → 要显示等级只能逐行拉 `xd_detail.html`（App：`competitionPublicityAwardProvider`，
卡片进视口才请求）。两个来源字段的实测分布（2026-09-16，公示第 1 页 20 条全量拉完）：

| 字段 | 形态 | 实测 |
|---|---|---|
| `学生提交的奖项` | `input[readonly]`，值 `【赛别】奖项名` | **20/20 条都有**：`【校赛】参与未获奖` ×17、`【省赛】三等奖` ×2、`【校赛】一等奖` ×1 |
| `最终获得奖项` | `select[disabled]`，选项文案带分值 `特等奖(2)分` | **20 条全空**（还没评定）；评定后才写 `selected` |
| `个人得分` | `input[readonly]`，如 `0分` | 16 条 `0分`、4 条空 |

App 口径（`competitionAwardLevelOf` + `CompetitionAwardLevel.parse`）：**最终奖项非空则优先用它，
赛别沿用「学生提交的奖项」的 `【…】` 前缀**；否则用提交的奖项。解析时去掉 `(2)分` 分值后缀，
`无` 视为没有等级。展示为 `省赛 · 三等奖`（国赛金 / 省赛蓝 / 校赛绿 / 参与未获奖灰）。

## 4. 提交申请（`add.do`）

```
POST /admin/tzz/dektSubjectGame/add.do        （form-urlencoded）
gameId=<比赛 id>           必填（find_game 的 radio value）
remark=【赛别】奖项名       必填（getCredit 的 name 前面拼 game 的 data-level）
type=0|1                  0 个人 / 1 团队
team=<内部成员 id 分号相连>  团队必填，≥2 人（官网 setGame() 传的就是 radio value）
enclosure=<附件 id 逗号相连> 必填，先 upload.do 拿 id
→ {"type":"success","content":"申请成功"}  （失败时 type 非 success、content 是原因）
```

- **⚠ `add.do` 不做服务端校验**：全空表单也返回「申请成功」，但记录不落库（实测：
  库里行数不变）。所以前端必须比照官网 `checkSubmit` 自己拦（比赛 / 奖项 / 附件 / 团队人数）。
- 证书上传：`POST /admin/accessory/upload.do?system_dir_path=base/indexdownload`，multipart 字段名
  `accessorys`（`accessorys[]` / `file` 也能过，服务端只看文件），返回
  `{"type":"success","data":[{"id":641432,"name":"<uuid>.png","path":"/upload/base/indexdownload/"}]}`
  → `enclosure` 用 `data[].id`。
  官网前端限制：`jpg/jpeg/png`、单张 ≤ 3072KB、一次 ≤ 10 张。
- 删除：`POST delete.do`，参数是**数组** `ids[]=199963&ids[]=199962`（jQuery `$.ajax` 默认
  `traditional:false` 的序列化）；用 `ids=199963` 会 400。
