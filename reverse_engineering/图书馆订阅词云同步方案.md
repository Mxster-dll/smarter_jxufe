## 一、结论速览

**在没有任何云服务器的前提下，用江财图书馆「我的订阅」的订阅词当 App 设置的云端存储——可行，且全部关键未知已在真账号上验证。**
每条订阅词 = **100 个字符**的容器；用 **CJK 基本区汉字**编码 gzip 后的载荷；**三组冗余 + 双代轮转**保证任意时刻云端至少有一份完整快照。

## 四、协议（冻结）

### 单条订阅词的字符布局（恰好 100 字符）

```
勿删！智慧er江财云同步信息：  0  01  07  XX  <78 个汉字载荷>
└──────── 15 字 ────────┘  │  │   │   │   └─ CJK 基本区编码
                           │  │   │   └─ 2 字校验（汉字）
                           │  │   └─ 总片数（ASCII 两位）
                           │  └─ 片序号（ASCII 两位）
                           └─ 代号（ASCII 一位，0/1 交替）
```

- **识别规则（不依赖前缀文本）**：剥掉前 15 字 → 数字头能解出合法 `(代, 序, 总)` → 载荷全部落在 U+4E00–U+9FFF → 校验通过。前缀被服务端改写标点也不影响识别。
- **读回校验只覆盖「数字头 + 载荷」**，不覆盖前缀（避免误报数据损坏）。
- 载荷字符集 = U+4E00–U+9FFF（20,992 符号 = 14.357 bit/字 = 1.795 B/字）。避开 U+F900–FAFF（NFKC）、U+3000（空白）、Ext-B（4 字节）。

### 容量账（用实测数）

```
100 字/条 = 15 前缀 + 5 数字头 + 78 载荷 + 2 校验
当前载荷 853 B gzip ÷ 1.795 B/字 = 476 字 → ceil(476/78) = 7 片/份
三组（新版×2 + 旧版×1）                      = 21 条词
天花板（已验证 70 条 ÷ 3 组）= 23 片/份 × 78 字 = 1794 汉字 ≈ gzip 3.2 KB ≈ 原始 JSON ~10 KB
当前占用 29%，余量 4.3 倍
```

### 三个动作

- **上传**：变更防抖 60s / 手动 / 回前台 → 组快照 → gzip → 抽 uuid → 分片 → 编码 → **写入最旧的那组** → 逐片读回校验 → 通过后**再写第二份**（最新版×2）→ 对账 `list` → 收工。任一步失败：不删任何东西，旧版仍在。
- **恢复**：`list` → 按前缀筛出三组 → 每组逐片校验 → 取校验全通过且版本号最新的那组 → 展示可读摘要（`2026-09-17 14:22 的快照 · 10 门课 · 5 项偏好 · 1.2 KB`）→ 两步确认 → **先把本机现状留档** → 解码 + 本地重新生成 uuid → 写入本机 box。
- **清除**：按前缀全删 → `list` 对账 → 残留为 0 才算成功。

### 用户实测反馈（2026-09-17 二轮）：「目前从云端同步似乎设置不会变」（已修）

**现象**：点「从云端恢复」→ 提示恢复成功，但**界面上的设置一动不动**（重启 App 才看到新值）。

**根因**（代码级确证，不是猜的）：恢复走的是 `HiveLibspLocalStore.writePrefs` → `box.put`，**只改了盘**；而 5 个偏好 store（外观 / 校区 / 主页布局 / 校历 / 入馆教育）都是「值读一次就存内存」（`ensureLoaded()` 里 `_loading ??= _load()` 幂等缓存，之后**再没人读盘**），全仓唯一的 `box.watch()` 是给防抖用的 `LibspDirtyWatcher`，它只通知「有改动」、**不去刷新内存** → 盘上是云端值，内存里还是旧值，界面自然不变。

**修法**（两条腿）：
1. **偏好 store 订阅自己的 box** = 新增 `lib/core/storage/box_reload_watcher.dart` 的 `BoxReloadWatcher` mixin：`_load()` 里 `bindBoxReload(box, _readFromBox)`，并把首载读取逻辑抽成 `_readFromBox(Box<String>)` 供两处共用；**判等相等就不通知**（自己 `save()` 写盘走回来时静默，不形成回环），`dispose()` 之后到达的事件直接丢弃（否则 `notifyListeners()` 抛「A ChangeNotifier was used after being disposed」）。覆盖 `theme_prefs.dart` / `my_campus_prefs.dart` / `home_layout_prefs.dart` / `calendar_prefs.dart` / `tsgxs_prefs.dart`（`electricityBinding` 不在其列：它是 `FutureProvider<Box<String>>`，页面每次读 box 本体）。
2. **把数据读进 State 的页面**（分数估计 / 综测）走新信号：`LibspSyncController.onRestored`（装配在 `libspSyncControllerProvider`）→ `localDataRevisionProvider`（`lib/core/storage/local_data_revision.dart`）`.bump()`；两页在 `build` 里 `ref.listen(...)` 重读（综测只重读手册、不触发体测自动源；分数估计走既有 `_reload()`）。
