## 周期与程序
- 每学年一次：非毕业学年每年 9 月对上一学年；毕业学年每年 5 月。
- 程序：学生自评（填表 + 加分项**原始证明材料**）→ 班级评议（民主评议无记名打分，去最高最低 5% 取平均）→ 学院核查 → 公示 ≥5 天 → 部门审核 → 学校审定。
- 弄虚作假：扣加分、通报、当年度综测不合格（第十八条）。

## 单项等次 gradeOf(score, rank)（第十条）
- score < 60 → **不合格(fail)**；≥75 且 rank≠below → **优秀(ok)**；≥65 且 rank≠below → **良好(good)**；否则 **合格(pass)**。
- rank：前30% top30 / 前30~60% top60 / 60%后 below / 未知 unknown（unknown 视同非 below，按分数判断，结果偏乐观）。
- 体育红线：体测 <60 直接 fail（tGrade = tScore<60 ? fail : gradeOf(tTotal, rank)）。

## 综合等次（表 2，代码 order）
```
tml = [体育,美育,劳育] 等次
若 d==fail 或 z==fail           → fail
否则若 tml 中 fail ≥2            → fail
否则若 d==ok 且 z==ok 且 tml 全 ∈{ok,good} → ok
否则若 d,z ∈{ok,good} 且 tml 无 fail      → good
否则                                → pass
```

## 五育公式与加分/扣分明细（数值全取自原 HTML）

### 德育 = 60 基础 + 民主评议(0~20) + 附加(≤20) − 扣分
- 评议构成（第十二条·2）：思想政治 8 + 社会公德 3 + 遵纪守法 3 + 集体观念 3 + 行为规范 3 = 20。
- 附加分（四部分可累计合计 ≤20）：
  - ① 优秀事迹 d-shi（单选一次，就高）：国家级 5（征兵入伍/退役、西部计划、三支一扶）/ 省部级 5（好人好事表扬信）/ 校级市厅级 3 / 院级县处级 2 / 班级 1。
  - ② 思想教育贡献度 d-sx（单选）：省级培训 5 / 校级培训 3 / 院级培训 1；**参与度 d-sx-n**：0.5 分/次 上限 2。
  - ③ 公共服务 d-fw（单选就高，档位 ×考核系数：优秀 ×1 / 合格 ×0.75；优秀比例 ≤30%，不合格不加分）：国家级负责人 5/4、省部级 4/3、校级组织负责人 3.5/2.5、校级部门负责人 3/2.5、院级组织负责人 3/2.5、院级部门负责人 2.5/1.5、班长团支书 2.5/1.5、班委委员 2/1。
  - ④ 荣誉称号：个人 d-hr-p 国家 10/省 5/市 4/校 2/院 1；集体 d-hr-g（负责人 ×1 / 其他 ×0.75? —— 表7 主要负责人/其他负责人/一般成员 = 4,3,2/3,2,1/2,1,0/1,0,0；HTML select 仅 国家4/省3/市2/校1 × 是否主要负责人 1:0.75，未实现成员档）；**个人+集体合计 ≤10**。
- 扣分：无故缺课 2/节 + 缺席重大集体活动 1/次 + 处分（学院通报 2 / 学校警告 5 / 严重警告 10）。
- 一票否决（任一 → 德育不合格）：司法公安处罚 / 测评弄虚作假 / 记过以上处分 / 考试舞弊学术不端。

### 智育 = 课程加权平均成绩 + 加分(≤20) − 扣分
- 加权成绩：教务系统读取（毕业班用毕业加权）；**App 已有 WeightedGrade 可自动带**。
- 加分（四类，≤20）：
  - ① 学科技能竞赛（Ⅰ~Ⅳ类统一口径）：奖项全部中最高项 **>5 分 → 只计最高项**；最高项 ≤5 → **累加多项封顶 5 分**。COMP 分级 × lvl(国 g/省 s/校 x) × prize(特等/一/二/三/参与)：
    - Ⅰ类 c1：g[20,18,15,12,null] s[12,10,8,5,null] x[5,4,3,2,0.3]
    - Ⅱ类 c2：g[12,10,8,5,null] s[5,4,3,2,null] x[2,1.5,1,0.5,0.1]
    - Ⅲ类 c3：g[5,4,3,2,null] s[2,1.5,1,0.5,null] x[1,0.5,0.25,0.2,0.1]
    - Ⅳ类 c4：g[2,1.5,1,0.5,null] s[1,0.5,0.25,0.2,null] x[0.5,0.4,0.3,0.2,0.1]
  - ② 学术能力（论文/专利）**可累计**：等级系数 × 作者贡献系数。PAPER：国际权威 20 / 国内权威 15 / CSSCI(国际会议) 12 / 北大核心 10 / 专业相关专利发明 1 / 国内一般(国内会议) 0.5。ORDER 贡献：第1作者 1 / 第2 0.6 / 第3 0.4 / 第4 0.2 / 第5+ 0.1。限制：gen 类累计 ≤1.5；无 intl/auth/csci 破格时 total ≤5。
  - ③ 外语能力（取最高一项）：雅思≥6.5 2/6~6.5 1、托福≥93 2/78~93 1、GRE≥320 2/310~320 1、日语 N1 2/N2 1、英日专八 2/专四 1、韩语 TOPIK6 2/4 1、六级≥425 2/四级≥425 1；艺术体育类专业四六级 ×1.5。tip：外语类上限 4 分。
  - ④ 自主创业：三年及以上 4 / 两年 3 / 一年 2 / 一年以内 1。
- 扣分：无故不参加实习实训/课外学术创新 3/次。
- 特殊情况：测评年度有挂科 → 智育最高合格（ok→good、good→pass）；退学警告/毕业未获资格 → fail。

### 体育 = 体质测试成绩 + 加分(≤20) − 扣分（体测<60 直接不合格）
- 体测成绩：0~100（免测/未测按 60；残疾免测由学院认定）。
- 加分：
  - ① 体育竞赛 **可累计**：SPORT lvl(国/省/校) × place(破纪录/一/二/三/四/五/六/七八名)：g[30,20,18,16,14,12,10,8] s[20,15,13,11,9,7,5,3] x[15,10,8,6,4,3,2,1]
  - ② 心理健康活动 **可累计**：PSYCH lvl(国 g/省 s/校 x/院 y) × prize(一/二/三/优胜)：g[10,8,6,4] s[8,6,4,2] x[6,4,2,1] y[3,2,1,0]
  - ③ 集体活动（单选）：校运动队 4（名单在列每场必到）/ 院运动队 2 / 班级突出 1（≤10%）。运动队两次不到取消该项。
- 扣分：当众扰乱秩序 5/次；参赛无故弃权/中途退场 2/次。

### 美育 = 60 基础 + 民主评议(0~20) + 附加(≤20) − 扣分
- 评议构成：才艺修养 5 + 活动参与 5 + 审美观 5 + 文艺贡献 5。
- 附加：
  - ① 文艺竞赛 **可累计**：ARTS lvl(国/省/校) × prize(一/二/三/未获奖)：g[10,8,6,4] s[8,6,4,2] x[6,4,2,1]
  - ② 媒体艺术（发表作品，需刊物原件，录用通知无效；不同作品可累计、同一作品只计最高）：国家级权威媒体(一报一社一台) 10/篇、国家级媒体及官微 8、省级媒体及官微 6、市(校)级 4、**院级 2 且累计 ≤10**。
  - ③ 美育活动（主持/表演，主办方认定称职）：省级及以上 10/6、校级 8/5、院级 6/4、班级 3/2。
- 扣分：文艺活动扰乱 1/次；艺术团未满服务期退团 2；代表参赛弃权/退场 5。

### 劳育 = 60 基础 + 民主评议(0~20) + 附加(≤20) − 扣分
- 评议构成：劳动观念 5 + 劳动情感 5 + 劳动实践 10。
- 附加：
  - ① 志愿服务时长（档位，以第二课堂导出/志愿记录为准）：每学年累计 100h→10 / 50h→8 / 30h→6 / 20h→4 / 15h→2 / 10h→1。
  - ② 社会实践 **可累计** SOCIAL lvl(国/省/校/院)：优秀团队负责人 [10,8,6,4]、优秀团队成员 [8,6,4,2]、先进个人 [10,6,4,2]、优秀调查报告 [10,6,4,2]、表彰或书面表扬 [10,6,4,2]、实践团队负责人 [6,5,4,3]、实践团队成员 [4,3,2,1]。
  - ③ 劳育活动（实习/实训/生产劳动）**可累计** LABOR × grade(优秀/合格)：专业实习 4/2、实训教学 4/2、参与生产劳动活动 2/1。
  - ④ 文明寝室（单选）：映山红文明寝室标兵 10 / 映山红文明寝室 8 / 校级表扬 6 / 院级表扬 4。
- 扣分：未参加校院组织劳育活动 1/次；大学期间未实习（大四认定）2；寝室卫生通报 院 2/校 4。
