# design/icons/

应用图标的设计稿与候选版本放这里（**源文件**，不进 APK）。

## 该放什么

- 各轮图标候选的大图导出（不同取景比例、不同底色、不同构图的对比图）
- 图标在真实场景里的截图（桌面、任务栏、设置页）
- 需要留档的第三方工具输出（如各尺寸阶梯、遮罩预览）

## 不该放什么

- **不要**放生成物本身（`mipmap-*/ic_launcher.png`、`app_icon.ico`）——那些由 `../logo/build-icons.cjs` 直接写到各端目录，放这里会出现同一份图两处、改了一处忘另一处
- **不要**放 App 运行时读取的图——那属于 `assets/images/`，还要在 `pubspec.yaml` 声明

## 命名建议

`<日期>-<主题>-<版本>.<ext>`，例如 `2026-10-08-取景对比-1.12x.png`，便于回溯是哪一轮的决策。
