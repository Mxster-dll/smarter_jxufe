# design/ui/

界面设计稿、原型截图、标注图放这里（**源文件**，不进 APK）。

## 该放什么

- 页面布局稿（主页宫格、侧栏、仪表盘、综测页等）
- 原型工具导出的截图（Figma / 即时设计 / 手绘拍照都行）
- 布局标注图（间距、字号、颜色取值）

## 和 `lib/design/` 的区别（别搞混）

| 路径 | 是什么 |
|---|---|
| `design/ui/`（本目录，仓库根） | **设计源文件**：图、稿子、截图 |
| `lib/design/`（Dart 包） | **代码里的设计口径**：`AppColors` / `appSectionTitle` / 三态组件等，被页面直接 import |

设计稿定下来后，真正的"口径"要落到 `lib/design/` 的代码里（并在 `docs/agents/` 记一笔），
本目录只留图，不要指望后来的人从图里读数值。

## 命名建议

`<日期>-<页面>-<状态>.<ext>`，例如 `2026-10-08-主页-宫格编辑态.png`。
